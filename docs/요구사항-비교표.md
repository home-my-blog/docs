# 요구사항 비교표 (4개 문서)

> 2026-10-02 기준입니다. 팀원 4명의 요구사항 문서를 기능별로 나란히 놓고, **누가 무엇을 갖고 있는지** 한눈에 보려는 표입니다.
> 이 표를 바탕으로 정리한 공통 기능은 [요구사항-공통.md](요구사항-공통.md)에 있습니다.

## 1. 비교한 문서

| 문서 | 컨셉 | 특징 |
|---|---|---|
| **MyBlog** (우리) | 여러 블로그가 모인 포털 | 주제 분류, 커뮤니티, 오늘의 이슈, 실시간 인기 검색어 |
| **OwnLog** | 멀티유저 블로그 (**1인 1블로그**) | 기능 ID 표, MVP와 2차 개발 구분 |
| **끄적** | **개인 다이어리** (다이어리 여러 권에 끄적을 쓴다) | 1차는 나만 보는 기록장. 공개·댓글·둘러보기는 "나중에" |
| **Ylog** | 티스토리형 (**1인 여러 블로그**) | 기능 32개, UI 구현 현황, 데이터 모델, 일정(10/1~10/14) |

## 2. 표시 설명

| 표시 | 뜻 |
|---|---|
| ● | 문서에 있고 1차(MVP) 범위입니다. |
| ○ | 있지만 후순위이거나 "나중에", 또는 화면이 아직 없습니다. |
| △ | 일부만 있거나 형태가 다릅니다. |
| - | 문서에 없습니다. |

> 우리 칸은 `docs/요구사항.md`를 다시 확인해서 채웠습니다. (이전에 대화로 드린 표와 다른 칸이 있을 수 있습니다.)

## 6. 알아 둘 점

- **컨셉이 달라서 공통 기능은 최소선입니다.** 끄적은 1차가 개인 기록장이라 "남의 글을 읽는 기능"이 없고, 우리는 포털 구조라 기능이 다른 쪽에 많습니다.
- **용어가 다릅니다.** 카테고리 / 다이어리, 블로그 / 다이어리를 공통 문서에서는 "분류", "공간"으로 통일했습니다.
- **끄적의 다이어리**는 공간과 분류를 겸하는 것으로 읽혔는데, 맞는지 작성자 확인이 필요합니다.
- Ylog 문서에 **일정(2026-10-01 ~ 10-14)**이 적혀 있습니다. 팀 전체의 마감인지 확인이 필요합니다.
- Ylog 문서의 **데이터 모델**(회원, 블로그, 카테고리, 글, 댓글, 태그, 좋아요, 구독)은 나중에 ERD를 만들 때 참고할 만합니다.
- 이 비교는 **문서에 적힌 내용**만 기준입니다. 실제 구현 상태나 작성자의 의도는 반영하지 못했을 수 있습니다.

## 7. 회의에서 정할 질문

회의 결과를 [요구사항-공통.md](요구사항-공통.md)의 `회의 결과` 칸에 적습니다.

- [ ] 공통 필수 13개(CF-01~13)에 모두 동의하는가?
- [ ] **공간 개수**: 공통은 "1개 이상"으로 쓰고 개수는 각자 정할까? (충돌 ①)
- [ ] **방문자 읽기**를 공통 필수가 아닌 **권장**으로 둘까? (충돌 ⑥, 끄적 때문에)
- [ ] 공통 권장 중 **함께 구현하자고 합의할 것**이 있는가? (예: 댓글, 좋아요, 태그)
- [ ] **이미지 업로드**를 공통에 넣을까? (저장 방식을 정해야 해서 부담이 큼)
- [ ] 기능 ID 접두어와 문서 말투를 통일할까?
