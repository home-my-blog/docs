## 용어 한눈에 보기

| 용어 | 쉬운 뜻 |
|---|---|
| 서버 프로그램 | DB, Redis처럼 **켜져 있으면서 요청을 받아 주는 프로그램** |
| 라이브러리 | 서버 프로그램에 **접속하는 방법**을 담은 코드 꾸러미 |
| Docker (도커) | 프로그램을 설치 없이 실행할 수 있게 **상자에 담는** 도구 |
| 이미지 | 상자의 원본. 프로그램과 설정이 다 들어 있는 꾸러미 (밀키트) |
| 컨테이너 | 이미지를 실제로 켜서 돌아가는 상자 (밀키트로 만든 요리) |
| 볼륨 | 상자를 지워도 **데이터가 남는 저장 공간** (냉장고) |
| 포트 | 프로그램에 접속하는 문 번호 |
| Docker Compose | 상자 여러 개를 **주문서 한 장**으로 켜고 끄는 도구 (개발용) |
| Kubernetes | 서버 여러 대 위에서 상자를 **자동으로 관리하는** 도구 (배포·운영용) |
| MinIO | 이미지 같은 **파일을 보관하는** 저장소 서버 |
| 배포 | 내 컴퓨터가 아닌 곳에 올려서 **다른 사람이 쓸 수 있게** 하는 것 |
