# 03. 코어: 블로그·분류·글

> 서비스의 핵심입니다. 블로그를 만들고, 분류로 나누고, 글을 쓰고 읽는 규칙입니다.
> 관련 파일: [01-인증-인가](01-인증-인가.md), [04-탐색](04-탐색.md), [05-소통-부가](05-소통-부가.md)
> 읽는 법과 ID 규칙은 [00-목차.md](00-목차.md)를 봅니다.

## 요구사항

### 블로그 (CF-03, CF-04) — 상태: 화면 없음 (내 블로그로 이동하는 것만 데모)

| ID | 요구사항 | 상세 |
|---|---|---|
| CF-03-1 | 개수 | 회원 1명이 **블로그 1개**를 가진다. (여러 개는 나중에 확장) |
| CF-03-2 | 생성 시점 | **가입이 완료되면** 블로그가 자동으로 만들어진다. 기본 이름은 "{닉네임}의 블로그"이고 소개는 비어 있다. |
| CF-03-3 | 기본 분류 | 블로그가 만들어질 때 분류 **"미분류"**가 함께 만들어진다. (모든 글은 분류에 속해야 하므로) |
| CF-04-1 | 이름 | 필수, 1~30자. 앞뒤 공백은 지운다. |
| CF-04-2 | 소개 | 선택, 0~200자. |
| CF-04-3 | 수정 | **블로그 주인만** 이름과 소개를 바꿀 수 있다. 저장하면 모든 화면에 바로 반영된다. |
| CF-04-4 | 삭제 | 이번 범위에서는 따로 만들지 않는다. (회원 탈퇴 때 함께 삭제된다.) |

### 글 (CF-05, CF-06, CF-09, CF-13) — 상태: 상세·목록은 `화면 있음`, 쓰기·수정·삭제는 `화면 없음`

#### 글 작성·수정·삭제 (CF-05, CF-06)

| ID | 요구사항 | 상세 |
|---|---|---|
| CF-05-1 | 작성 권한 | 로그인한 회원이 **자기 블로그에만** 쓸 수 있다. 로그인하지 않았다면 CF-16-1을 따른다. |
| CF-05-2 | 입력 항목 | 제목, 본문, 분류, 공개 여부를 입력한다. |
| CF-05-3 | 제목 | 필수, 1~100자. 앞뒤 공백은 지운다. 공백만 쓰면 비어 있는 것으로 본다. |
| CF-05-4 | 본문 | **필수**(CF-06), 1~10,000자. 줄바꿈은 그대로 보여 주고, 글자만 쓸 수 있다. |
| CF-05-5 | 분류 | 필수. 내 블로그의 분류 중 하나를 고른다. 기본값은 마지막에 쓴 글의 분류이고, 처음에는 "미분류"이다. |
| CF-05-6 | 공개 여부 | 기본값은 **공개**이다. (CF-13) |
| CF-05-7 | 작성 시각 | 저장하는 순간 자동으로 기록한다. 사용자가 바꿀 수 없다. |
| CF-05-8 | 저장 후 | 저장하면 그 글의 상세 화면으로 이동한다. 저장에 실패하면 입력한 내용을 그대로 둔다. |
| CF-05-9 | 오류 표시 | 필수 칸이 비어 있으면 칸 아래에 알려 준다. |
| CF-05-10 | 이탈 확인 | 입력하던 중 나가려 하면 "저장하지 않은 내용이 있습니다. 나갈까요?"를 묻는다. |
| CF-05-11 | 중복 제출 방지 | 저장을 연속으로 눌러도 한 번만 처리한다. |
| CF-05-12 | 수정 권한 | **작성자 본인만** 고칠 수 있다.(CF-12) 남의 글의 수정 주소로 들어오면 "존재하지 않는 글입니다"를 보여 준다. |
| CF-05-13 | 수정 범위 | 제목, 본문, 분류, 공개 여부를 바꿀 수 있다. 작성 시각은 그대로 두고, **내용이 바뀌었을 때만** 수정 시각을 갱신한다. |
| CF-05-14 | 삭제 | 작성자 본인만 지울 수 있다. "삭제하면 되돌릴 수 없습니다. 삭제할까요?"로 확인한 뒤 지운다. |
| CF-05-15 | 삭제 후 | 그 글에 달린 댓글, 좋아요, 태그 연결, 이미지도 함께 지우고, 내 블로그 글 목록으로 이동한다. |

#### 글 상세 (CF-09)

| ID | 요구사항 | 상세 |
|---|---|---|
| CF-09-1 | 보이는 정보 | 분류, 제목, 블로그 이름, 작성 시각, 본문을 보여 준다. 수정한 적이 있으면 수정 시각도 보여 준다. |
| CF-09-2 | 이전·다음 글 | 같은 블로그의 **공개 글**을 작성 시각 순서로 이동한다. 이전 글이나 다음 글이 없으면 그쪽 버튼은 숨긴다. |
| CF-09-3 | 목록으로 | 그 글이 속한 분류의 글 목록으로 돌아간다. |
| CF-09-4 | 볼 수 없는 글 | 없는 글이거나 남의 **비공개 글**이면 둘 다 "존재하지 않는 글입니다"를 보여 준다. (비공개 글이 있다는 사실도 알려 주지 않는다.) |
| CF-09-5 | 작성자 메뉴 | 작성자 본인에게만 `수정`, `삭제` 버튼이 보인다. |

#### 공개 범위 (CF-13)

| ID | 요구사항 | 상세 |
|---|---|---|
| CF-13-1 | 단위 | 글 하나마다 정한다. |
| CF-13-2 | 값 | **공개** 또는 **비공개**이다. 기본값은 공개이다. |
| CF-13-3 | 공개 글 | 누구나 읽을 수 있고, 글 목록·검색·이전/다음 글에 나온다. |
| CF-13-4 | 비공개 글 | **작성자 본인만** 볼 수 있다. 다른 사람에게는 목록, 검색, 이전/다음 글, 주소 접근 어디에도 나타나지 않는다. |
| CF-13-5 | 본인 화면 | 내 블로그의 글 목록에서는 비공개 글에 "비공개" 표시를 붙여 보여 준다. |
| CF-13-6 | 바꾸기 | 언제든 바꿀 수 있고 바로 반영된다. 비공개를 공개로 바꿀 때는 "공개로 바꾸면 누구나 볼 수 있습니다"를 확인한다. |

### 분류 (CF-07, CF-08) — 상태: 보기는 `화면 있음`, 관리는 `화면 없음`

| ID | 요구사항 | 상세 |
|---|---|---|
| CF-07-1 | 소속 | 모든 글은 **정확히 하나의 분류**에 속한다. 분류가 없는 글은 없다. |
| CF-08-1 | 관리 권한 | **블로그 주인만** 분류를 추가·수정·삭제할 수 있다. |
| CF-08-2 | 이름 | 필수, 1~20자. 앞뒤 공백은 지우고, **같은 블로그 안에서 겹칠 수 없다.** (영문 대소문자는 같은 것으로 본다.) |
| CF-08-3 | 추가 | 이름을 입력하면 목록 맨 아래에 추가된다. |
| CF-08-4 | 이름 바꾸기 | 이름을 바꾸면 그 분류의 글에 바로 반영된다. |
| CF-08-5 | 순서 | 순서를 바꿀 수 있고, 블로그 화면의 분류 목록에도 같은 순서로 나온다. |
| CF-08-6 | **삭제 조건** | **글이 하나라도 있으면 삭제할 수 없다.** 글을 다른 분류로 옮긴 뒤에 지울 수 있다. |
| CF-08-7 | 글 옮기기 | 글을 옮기려면 글 수정에서 분류를 바꾼다. |
| CF-08-8 | 기본 분류 | "미분류"는 삭제할 수 없고, 이름은 바꿀 수 있다. 그래서 분류는 항상 1개 이상 있다. |
| CF-08-9 | 글 개수 | 분류 이름 옆에 글 개수를 보여 준다. 방문자에게는 **공개 글만**, 블로그 주인에게는 비공개 글도 포함해서 센다. |

### 안내 문구

화면에 보여 줄 문구 예시입니다. 말투는 "~합니다 / ~해 주세요"로 통일합니다.

| 상황 | 문구 |
|---|---|
| 제목 없음 | "제목을 입력해 주세요" |
| 본문 없음 | "본문을 입력해 주세요" |
| 저장 전 이탈 | "저장하지 않은 내용이 있습니다. 나갈까요?" |
| 글 삭제 확인 | "삭제하면 되돌릴 수 없습니다. 삭제할까요?" |
| 공개로 전환 | "공개로 바꾸면 누구나 볼 수 있습니다" |
| 없는 글·볼 수 없는 글 | "존재하지 않는 글입니다" |
| 분류 이름 중복 | "이미 있는 분류입니다" |
| 분류 삭제 불가 | "이 분류에 글이 {N}개 있어 삭제할 수 없습니다. 글을 다른 분류로 옮긴 뒤 삭제해 주세요" |

### 기본값 (바꿀 수 있는 숫자)

| 항목 | 값 | 관련 ID |
|---|---|---|
| 블로그 이름 / 소개 | 1~30자 / 0~200자 | CF-04-1, 2 |
| 글 제목 / 본문 | 1~100자 / 1~10,000자 | CF-05-3, 4 |
| 분류 이름 | 1~20자 | CF-08-2 |

### 정하지 못한 것

- **블로그를 여러 개 만들 수 있게 할지**: 지금은 1인 1블로그입니다.

## 구현 방식

> 상태 표기: **확정**(정했음) / **가안**(바뀔 수 있음) / **미정**(아직 정하지 않음). 자세한 기술 설명과 그림은 [기술스택-아키텍처.md](../기술스택-아키텍처.md)에 있습니다.

> **작성 예정**입니다. ERD 단계에서 표와 칸을 정리하면서 채웁니다.
>
> | 미리 정해 둔 것 | 내용 |
> |---|---|
> | 쓰는 DB 표 | 블로그, 분류, 글 (회원–블로그는 **1:N 구조**로 만들고 서버에서 "1개까지"로 제한) |
> | 세션을 쓰는 지점 | 글을 쓰거나 고칠 때 **글 주인 == 로그인한 회원**인지 확인한다 (그림: [기술스택-아키텍처.md 3장 D](../기술스택-아키텍처.md)) |
> | 본문 저장 | 글자 한 칸으로 저장한다. 편집기를 쓰게 되면 마크다운으로 저장하는 안을 추천 |
> | DB 제약 | 글이 있는 분류는 삭제할 수 없게 DB에서도 막는 안, 분류 이름의 블로그 안 중복 불가 (제안) |
> | 트랜잭션 | 글 삭제 시 댓글·좋아요·이미지 기록을 한 묶음으로 함께 지운다 |
