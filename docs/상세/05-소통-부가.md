# 05. 소통·부가: 댓글·좋아요·태그·신고·이미지

> 글에 반응하고 덧붙이는 기능의 규칙입니다. 관리자 기능과 외부 인증 제외도 여기에 둡니다.
> 관련 파일: [03-코어-블로그-글](03-코어-블로그-글.md), [06-블로그관리-통계](06-블로그관리-통계.md)
> 읽는 법과 ID 규칙은 [00-목차.md](00-목차.md)를 봅니다.

## 요구사항

### 소통·부가 기능 (CF-18 ~ CF-24) — 상태: 화면 없음

#### 댓글 (CF-18)
| ID | 요구사항 | 상세 |
|---|---|---|
| CF-18-1 | 작성 권한 | **로그인한 회원만** 쓸 수 있다. 비회원에게는 입력칸 대신 "로그인한 회원만 댓글을 쓸 수 있습니다"와 로그인 버튼을 보여 준다. |
| CF-18-2 | 내용 | 1~500자. 공백만 쓸 수 없다. 줄바꿈은 허용한다. |
| CF-18-3 | 표시 | 작성자 닉네임, 작성 시각, 내용을 보여 준다. **오래된 댓글이 위**에 오고, 글 상세에 댓글 수를 보여 준다. |
| CF-18-4 | 삭제 | **댓글 작성자 본인**과 **그 글을 쓴 블로그 주인**이 지울 수 있다. "댓글을 삭제할까요?"로 확인한 뒤 지운다. |
| CF-18-5 | 수정 | 이번 범위에서는 만들지 않는다. (지우고 다시 쓴다.) |
| CF-18-6 | 글 삭제·탈퇴 | 글을 지우면 댓글도 함께 지운다. 작성자가 탈퇴하면 댓글은 남고 작성자는 "탈퇴한 사용자"로 표시한다. |
| CF-18-7 | 연속 등록 | 같은 사람이 5초 안에 여러 번 등록할 수 없다. |

#### 좋아요 (CF-19)
| ID | 요구사항 | 상세 |
|---|---|---|
| CF-19-1 | 권한 | 로그인한 회원만 누를 수 있다. 비회원이 누르면 CF-16-1을 따른다. |
| CF-19-2 | 규칙 | 한 회원이 한 글에 **한 번**만 누를 수 있고, 다시 누르면 취소된다. |
| CF-19-3 | 표시 | 글 상세에 개수를 보여 주고, 내가 눌렀는지 표시한다. |
| CF-19-4 | 자기 글 | 자기 글에는 누를 수 없다. |

#### 태그 (CF-20)
| ID | 요구사항 | 상세 |
|---|---|---|
| CF-20-1 | 붙이기 | 글마다 **최대 5개**이고, 붙이지 않아도 된다. |
| CF-20-2 | 규칙 | 1~15자. 공백과 쉼표는 쓸 수 없다. 같은 글에서 겹칠 수 없다. 앞의 `#`은 자동으로 지우고, 대소문자는 구분하지 않는다. |
| CF-20-3 | 보기 | 글 상세 아래에 태그를 보여 준다. 태그를 누르면 같은 태그가 붙은 **공개 글** 목록을 보여 준다. |
| CF-20-4 | 수정 | 글 수정에서 태그를 추가하거나 지울 수 있다. |

#### 신고 (CF-21)
| ID | 요구사항 | 상세 |
|---|---|---|
| CF-21-1 | 권한 | 로그인한 회원만 신고할 수 있다. **자기 글은 신고할 수 없다.** |
| CF-21-2 | 사유 | 스팸 / 욕설·혐오 / 음란물 / 기타 중 하나를 고른다. 기타는 설명을 0~200자로 쓸 수 있다. |
| CF-21-3 | 중복 | 같은 회원이 같은 글을 두 번 신고할 수 없다. |
| CF-21-4 | 처리 | 이번 범위에서는 **접수만 저장**한다. 처리는 관리자 기능(CF-23)과 함께 나중에 만든다. |
| CF-21-5 | 접수 후 | "신고가 접수되었습니다"를 보여 준다. |

#### 이미지 업로드 (CF-22)
| ID | 요구사항 | 상세 |
|---|---|---|
| CF-22-1 | 형식 | jpg, png, gif, webp만 올릴 수 있다. |
| CF-22-2 | 용량 | 한 장당 **5MB 이하**이다. |
| CF-22-3 | 개수 | 글 하나에 **최대 10장**이다. |
| CF-22-4 | 표시 | 본문 안에 보여 준다. 목록의 대표 이미지(썸네일)는 이번 범위에서 만들지 않는다. |
| CF-22-5 | 삭제 | 글을 지우면 그 글의 이미지도 함께 지운다. |

#### 관리자와 외부 인증 (CF-23, CF-24)
| ID | 요구사항 | 상세 |
|---|---|---|
| CF-23-1 | 관리자 | 이번 범위에서는 관리자 화면을 만들지 않는다. 신고 내용은 데이터베이스에서 직접 확인한다. |
| CF-24-1 | 외부 인증 | **소셜 로그인**(구글, 카카오, 네이버 계정으로 로그인)은 만들지 않는다. |
| CF-24-2 | 이메일 인증 | 이메일 인증은 만든다. (01-인증-인가.md의 '이메일 인증') |

### 안내 문구

화면에 보여 줄 문구 예시입니다. 말투는 "~합니다 / ~해 주세요"로 통일합니다.

| 상황 | 문구 |
|---|---|
| 비회원 댓글 | "로그인한 회원만 댓글을 쓸 수 있습니다" |
| 댓글 삭제 확인 | "댓글을 삭제할까요?" |
| 이미지 조건 | "이미지는 5MB 이하의 jpg, png, gif, webp만 올릴 수 있습니다" |
| 이미 신고함 | "이미 신고한 글입니다" |
| 신고 접수 | "신고가 접수되었습니다" |

### 기본값 (바꿀 수 있는 숫자)

| 항목 | 값 | 관련 ID |
|---|---|---|
| 댓글 | 1~500자, 연속 등록은 5초 간격 | CF-18-2, 7 |
| 태그 | 글당 5개, 1~15자 | CF-20-1, 2 |
| 신고 기타 사유 | 0~200자 | CF-21-2 |
| 이미지 | 5MB 이하, 글당 10장 | CF-22-2, 3 |

### 정하지 못한 것

- **이미지 저장 위치**: 서버 디스크 또는 외부 저장소
- **관리자 기능**을 언제 만들지

## 구현 방식

> 상태 표기: **확정**(정했음) / **가안**(바뀔 수 있음) / **미정**(아직 정하지 않음). 자세한 기술 설명과 그림은 [기술스택-아키텍처.md](../기술스택-아키텍처.md)에 있습니다.

> **작성 예정**입니다. ERD 단계에서 표와 칸을 정리하면서 채웁니다.
>
> | 미리 정해 둔 것 | 내용 |
> |---|---|
> | 쓰는 DB 표 | 댓글, 좋아요, 태그와 글-태그 연결, 신고, 글 이미지 기록 (모두 **나중에 추가해도 되는 표**) |
> | 세션을 쓰는 지점 | 댓글 삭제는 "작성자 본인 또는 그 글의 블로그 주인"인지 확인한다. 좋아요·신고는 로그인한 회원만, 자기 글은 제외 |
> | 이미지 | 파일은 DB가 아니라 저장소에 두고 DB에는 주소만 적는다. 저장소(서버 디스크 / MinIO)는 **미정**. 흐름은 [기술스택-아키텍처.md 3장 E](../기술스택-아키텍처.md) |
> | 연쇄 삭제 | 글을 지우면 그 글의 댓글·좋아요·태그 연결·이미지도 함께 지운다 |
