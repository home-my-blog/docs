# 07. 공통 규칙

> 모든 파트에 걸치는 규칙입니다. (보안 외 비기능, 입력 검증, 기술 스택 요약, 아직 정하지 못한 기술)
> 관련 파일: 모든 파트
> 읽는 법과 ID 규칙은 [00-목차.md](00-목차.md)를 봅니다.

## 비기능 요구사항 (보안 외)

| ID | 분류 | 요구사항 |
|---|---|---|
| NF-03 | 사용성 | 휴대폰 화면(폭 360px 이상)에서도 가로로 밀어 보지 않고 읽고 쓸 수 있다. |
| NF-07 | 보안 | 본문과 댓글에 스크립트를 넣어도 실행되지 않게 하고, 입력값으로 데이터베이스를 조작하지 못하게 한다. |
| NF-08 | 유지보수 | 글자 수 제한, 용량, 잠금 시간 같은 **기본값은 한곳에서 바꿀 수 있어야** 한다. (각 파트 파일의 '기본값' 표 참고) |
| NF-09 | 성능 | 글 목록과 글 상세는 **2초 안에** 보여 준다. |

### 기본값 (바꿀 수 있는 숫자)

| 항목 | 값 | 관련 ID |
|---|---|---|
| 응답 속도 | 2초 이내 | NF-09 |

## 구현 방식

> 상태 표기: **확정**(정했음) / **가안**(바뀔 수 있음) / **미정**(아직 정하지 않음). 자세한 기술 설명과 그림은 [기술스택-아키텍처.md](../기술스택-아키텍처.md)에 있습니다.

### 기술 스택

| 영역 | 구현 방식 | 상태 |
|---|---|---|
| 서버 구조 | **단일 서버.** 안은 기능별로 나눈다. (회원, 블로그, 글, 댓글, 검색 등) MSA는 하지 않는다 | 확정 |
| 서버 | Spring Boot (Java), Spring Security | 가안 |
| 화면 | React (Vite). 지금의 HTML 시안은 나중에 옮긴다 | 가안 |
| DB | PostgreSQL | 가안 |
| 통신 | REST API (JSON) | 가안 |
| Redis | **이메일 인증번호 저장에 쓴다** (만료 시간이 되면 자동으로 사라짐). 세션 저장은 PostgreSQL | 확정 |

### 입력 검증과 기타

| 영역 | 연결 ID | 구현 방식 | 상태 |
|---|---|---|---|
| 서버 입력 검사 | CF-01 ~ CF-22 | 서버에서 글자 수, 형식, 필수 여부를 검사한다 (Bean Validation). 화면 검사는 보조다 | 가안 |
| SQL 안전 처리 | NF-07 | JPA와 파라미터 바인딩을 쓴다. 문자열을 이어 붙여 쿼리를 만들지 않는다 | 가안 |
| 스크립트 안전 처리 | NF-07 | React의 기본 이스케이프를 쓰고, 본문은 글자만 허용한다 | 가안 |
| 기본값 설정 | NF-08 | 설정 파일 한곳(`application.yml`)에서 읽는다 | 가안 |

### 아직 정하지 못한 기술

| 항목 | 현재 생각 | 상태 |
|---|---|---|
| SMTP 발송 계정 | Gmail 또는 네이버 | 미정 |
| 이미지 저장 위치 | 서버 디스크로 시작하거나 외부 저장소 | 미정 |
| 배포 환경 | 서버, DB, 화면을 어디에 올릴지. HTTPS는 서버 앞단에서 처리 | 미정 |
| Redis 운영 | 이메일 인증번호에 쓰기로 했으므로 **설치와 실행이 필요**하다. 개발 환경에서는 내 컴퓨터에서 직접 실행하거나 컨테이너로 띄운다 | 가안 |
