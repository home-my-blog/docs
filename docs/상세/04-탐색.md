# 04. 탐색: 글 목록·검색

> 글을 찾아 읽는 규칙입니다. (글 목록, 키워드 검색, 방문자의 읽기)
> 관련 파일: [03-코어-블로그-글](03-코어-블로그-글.md)
> 읽는 법과 ID 규칙은 [00-목차.md](00-목차.md)를 봅니다.

## 요구사항

### 글 목록 (CF-10) — 상태: 화면 있음

| ID | 요구사항 | 상세 |
|---|---|---|
| CF-10-1 | 정렬 | 작성 시각 **내림차순**(최신이 위)이다. 시각이 같으면 나중에 만든 글이 위에 온다. |
| CF-10-2 | 나눠 보기 | 한 페이지에 **10개**씩 보여 주고, 아래에 페이지 번호를 보여 준다. |
| CF-10-3 | 페이지 이동 | 현재 페이지를 강조한다. `이전`, `다음` 버튼은 첫 페이지와 마지막 페이지에서 눌리지 않는다. |
| CF-10-4 | 없는 페이지 | 글 수보다 큰 페이지 번호로 들어오면 **마지막 페이지**를 보여 준다. (오류 화면을 보여 주지 않는다.) |
| CF-10-5 | 한 줄 정보 | 분류, 작성일, 제목, 본문 앞부분(**최대 100자**, 넘으면 "…")을 보여 준다. 줄바꿈은 공백으로 바꾼다. |
| CF-10-6 | 보이는 대상 | 방문자에게는 공개 글만 보여 준다. 블로그 주인이 자기 블로그를 볼 때는 비공개 글도 보여 준다. |
| CF-10-7 | 분류 필터 | 분류를 고르면 그 분류의 글만 보여 주고, 고르지 않으면 모든 글을 보여 준다. 페이지를 넘겨도 선택은 유지된다. |
| CF-10-8 | 빈 목록 | "글이 없습니다"를 보여 준다. 내 블로그라면 "첫 글을 써 보세요"와 `글쓰기` 버튼도 보여 준다. |
| CF-10-9 | 글 개수 | 목록 위에 "N개의 글"을 보여 준다. |

### 글 검색 (CF-11) — 상태: 화면 있음

| ID | 요구사항 | 상세 |
|---|---|---|
| CF-11-1 | 입력 | 검색어는 **2~50자**이다. 앞뒤 공백은 지운다. 공백만 입력하거나 1자만 입력하면 검색하지 않고 안내한다. |
| CF-11-2 | 대상 | **공개 글**의 제목과 본문에서 찾는다. 비공개 글은 항상 제외한다. |
| CF-11-3 | 여러 단어 | 공백으로 나눈 **모든 단어가 들어 있는 글**만 보여 준다. |
| CF-11-4 | 대소문자 | 구분하지 않는다. |
| CF-11-5 | 결과 정렬 | 작성 시각 내림차순이다. 한 페이지에 10개씩 나눠 보여 준다. |
| CF-11-6 | 결과 표시 | "검색 결과 N건"을 보여 주고, 각 결과에 블로그 이름, 분류, 작성일, 제목, 본문 앞부분을 보여 준다. |
| CF-11-7 | 결과 없음 | "검색 결과가 없습니다"를 보여 준다. |
| CF-11-8 | 검색어 유지 | 결과 화면의 검색창에 입력한 검색어가 그대로 남아 있다. |
| CF-11-9 | 특수문자 | 검색어에 특수문자가 있어도 오류 없이 일반 글자로 취급한다. (NF-07) |

### 방문자의 읽기 (CF-17)
| ID | 요구사항 | 상세 |
|---|---|---|
| CF-17-1 | 읽을 수 있는 범위 | 로그인하지 않아도 **공개 글**, 블로그 화면, 분류별 목록, 검색을 이용할 수 있다. |
| CF-17-2 | 쓰는 기능 | 글쓰기, 댓글, 좋아요, 신고, 마이페이지는 CF-16-1에 따라 로그인을 요구한다. |

### 안내 문구

화면에 보여 줄 문구 예시입니다. 말투는 "~합니다 / ~해 주세요"로 통일합니다.

| 상황 | 문구 |
|---|---|
| 빈 글 목록 | "글이 없습니다" |
| 검색어가 짧음 | "검색어를 2자 이상 입력해 주세요" |
| 검색 결과 없음 | "검색 결과가 없습니다" |

### 기본값 (바꿀 수 있는 숫자)

| 항목 | 값 | 관련 ID |
|---|---|---|
| 목록 한 페이지 글 수 | 10개 | CF-10-2 |
| 목록의 본문 미리보기 | 100자 | CF-10-5 |
| 검색어 | 2~50자 | CF-11-1 |

## 구현 방식

> 상태 표기: **확정**(정했음) / **가안**(바뀔 수 있음) / **미정**(아직 정하지 않음). 자세한 기술 설명과 그림은 [기술스택-아키텍처.md](../기술스택-아키텍처.md)에 있습니다.

### 글 검색

| 영역 | 연결 ID | 구현 방식 | 상태 |
|---|---|---|---|
| 검색 | CF-11 | 처음에는 PostgreSQL의 단순 포함 검색(대소문자 무시)으로 한다. 한국어 형태소 검색은 나중에 | 가안 |

> **작성 예정(나머지)**: 글 목록의 쿼리 방식(최신순 + 페이지 나눔, 비공개 글 제외 조건)과 정렬용 인덱스는 ERD 단계에서 정리합니다. 실시간 인기 검색어(개인 요구사항)의 계산 흐름은 [기술스택-아키텍처.md 3장 G](../기술스택-아키텍처.md)에 있습니다.
