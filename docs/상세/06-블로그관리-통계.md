# 06. 블로그 관리·통계

> 블로그 주인이 자기 블로그를 운영하는 화면의 규칙입니다. (대시보드, 글 관리, 분류 관리, 댓글 관리와 새 댓글 표시, 통계, 설정)
> 관련 파일: [02-계정관리](02-계정관리.md), [03-코어-블로그-글](03-코어-블로그-글.md), [05-소통-부가](05-소통-부가.md)
> 읽는 법과 ID 규칙은 [00-목차.md](00-목차.md)를 봅니다.

> **초안입니다.** 이 파트는 `요구사항-공통.md`에 없던 내용입니다. UI 시안(`manage.html`)과 대화에서 나온 내용을 처음 문서로 옮겼습니다. ID는 `BM-xx`(Blog Management)로 새로 붙였습니다.
> **'확인 필요'로 표시한 항목은 아직 합의하지 않았습니다.** 합의되면 표시를 지우고, 번복되면 이 파일을 먼저 고칩니다.

## 쉬운 설명: 마이페이지와 블로그 관리는 무엇이 다른가요?

| | **마이페이지** | **블로그 관리** |
|---|---|---|
| 한마디로 | **나**에 대한 설정 | **내 블로그**를 운영하는 곳 |
| 하는 일 | 닉네임·소개 수정, 비밀번호 변경, 회원 탈퇴 | 글 관리, 분류 관리, 댓글 확인, 통계 보기, 블로그 이름 수정 |
| 문서 | [02-계정관리.md](02-계정관리.md) | 이 파일 |
| 비유 | 신분증과 주소 변경 | 가게 사장님의 매장 관리실 |

티스토리도 계정 설정과 블로그 관리가 나뉘어 있습니다. 로그인하면 화면 위쪽 사용자 메뉴에서 두 곳으로 각각 들어갑니다.

**이렇게 쓰게 됩니다.** 서연이 아침에 `블로그 관리`를 엽니다.

1. **대시보드**에 어제 조회수 32, 방문자 21, 새 댓글 2개가 보입니다. 왼쪽 메뉴의 `댓글 관리` 옆에도 빨간 점과 숫자 2가 떠 있습니다.
2. `댓글 관리`를 누르면 새 댓글에 `NEW`가 붙어 있고, 댓글 아래의 글 제목을 누르면 그 글의 댓글 위치로 이동합니다. 이 화면을 열면 새 댓글이 "읽음"으로 바뀌고 숫자 2가 사라집니다.
3. `글 관리`에서 비공개로 써 둔 글을 찾아 공개로 바꾸고, `분류 관리`에서 분류 순서를 바꿉니다.
4. `통계`에서 최근 7일 동안 어느 날 방문자가 많았는지 그래프로 봅니다.

## 요구사항

### 블로그 관리 전체 (BM-01) — 상태: 화면 `데모`, 규칙은 아직 동작하지 않음

| ID | 요구사항 | 상세 |
|---|---|---|
| BM-01-1 | 구성 | 왼쪽에 메뉴, 오른쪽에 내용을 보여 준다. 메뉴는 **대시보드, 글 관리, 분류 관리, 댓글 관리, 통계, 설정**이다. 메뉴 위에는 블로그 이름, "내 블로그 보기", "글쓰기" 버튼을 둔다. |
| BM-01-2 | 접근 | **로그인한 블로그 주인만** 볼 수 있다. 로그인하지 않았으면 CF-16-1과 같이 로그인 창을 띄운다. 다른 회원의 관리 화면은 볼 수 없다. (서버에서 검사한다 — NF-02) |
| BM-01-3 | 마이페이지와 구분 | 계정 설정은 마이페이지(CF-15)에서, 블로그 운영은 이 화면에서 한다. 로그인 후 사용자 메뉴에 두 항목이 따로 있다. `확인 필요` |
| BM-01-4 | 이동 | "내 블로그 보기"를 누르면 방문자가 보는 내 블로그 화면으로 이동한다. |

### 대시보드 (BM-02)

| ID | 요구사항 | 상세 |
|---|---|---|
| BM-02-1 | 숫자 | **오늘·어제·누적 조회수**, **오늘·어제·누적 방문자**, **새 댓글 수**를 한눈에 보여 준다. |
| BM-02-2 | 그래프 | 최근 30일의 일별 조회수와 방문자를 선 그래프로 보여 준다. "통계 더 보기"를 누르면 통계 화면으로 간다. |
| BM-02-3 | 인기 글 | 최근 7일 동안 조회수가 많은 **공개 글 5개**를 제목과 조회수로 보여 준다. |
| BM-02-4 | 최근 글 | 최근에 쓴 글 5개를 작성일과 함께 보여 준다. 비공개 글에는 "비공개" 표시를 붙인다. |
| BM-02-5 | 새 댓글 | 새 댓글이 있으면 숫자를 강조해서 보여 주고, "댓글 보기"로 댓글 관리에 연결한다. |
| BM-02-6 | 빈 상태 | 글이나 댓글이 없으면 숫자는 0으로, 목록은 안내 문구로 보여 준다. |

### 글 관리 (BM-03) — 글을 쓰고 고치는 규칙은 CF-05, CF-06

| ID | 요구사항 | 상세 |
|---|---|---|
| BM-03-1 | 목록 | **비공개 글을 포함한 내 글 전체**를 최신순으로 보여 준다. 한 페이지에 10개씩 나눠 본다. |
| BM-03-2 | 표시 칸 | 제목, 분류, 작성일, 공개 여부, 조회수, 댓글 수를 보여 준다. |
| BM-03-3 | 거르기 | **공개 여부**(전체 / 공개 / 비공개)와 **분류**로 걸러 볼 수 있다. |
| BM-03-4 | 동작 | 글마다 **보기, 수정, 삭제**를 할 수 있다. 수정은 글 수정 화면(CF-06)으로, 삭제는 "삭제하면 되돌릴 수 없습니다. 삭제할까요?"로 확인한 뒤 지운다. |
| BM-03-5 | 글쓰기 | 목록 위에서 바로 글쓰기 화면으로 갈 수 있다. |
| BM-03-6 | 빈 상태 | 쓴 글이 없으면 "아직 쓴 글이 없습니다"와 글쓰기 버튼을, 거른 결과가 없으면 "글이 없습니다"를 보여 준다. |

### 분류 관리 (BM-04) — 분류 규칙은 CF-07, CF-08을 그대로 따른다

| ID | 요구사항 | 상세 |
|---|---|---|
| BM-04-1 | 화면 | 분류 목록을 순서대로 보여 주고, 분류마다 **이름과 글 개수**를 적는다. 목록 아래에 새 분류 입력칸이 있다. |
| BM-04-2 | 동작 | **추가, 이름 변경, 위·아래 순서 바꾸기, 삭제**를 이 화면에서 한다. 이름 글자 수, 중복, 삭제 조건, "미분류" 규칙은 CF-08-2 ~ 8을 따른다. |
| BM-04-3 | 구분 색 | 분류마다 구분용 색 점을 보여 준다. 새 분류의 색은 정해진 순서로 **자동 배정**하고, 직접 고르게 하지는 않는다. |
| BM-04-4 | 안내 | 화면 아래에 "글이 하나라도 있는 분류는 삭제할 수 없습니다. 글은 글 수정에서 다른 분류로 옮길 수 있습니다."를 항상 적어 둔다. |

### 댓글 관리와 새 댓글 표시 (BM-05) — 댓글 규칙은 CF-18

| ID | 요구사항 | 상세 |
|---|---|---|
| BM-05-1 | 목록 | **내 블로그 글에 달린 모든 댓글**을 **최신순**으로 보여 준다. (글 상세 화면은 오래된 댓글이 위이지만, 이 화면은 새 댓글을 먼저 보려는 곳이라 반대이다.) |
| BM-05-2 | 표시 칸 | 작성자 닉네임, 작성 시각, 내용 앞 50자, **댓글이 달린 글 제목**을 보여 준다. 글 제목을 누르면 그 글의 댓글 위치로 이동한다. 탈퇴한 작성자는 "탈퇴한 사용자"로 보여 준다(CF-18-6). |
| BM-05-3 | 삭제 | 블로그 주인은 내 글에 달린 **모든 댓글**을 지울 수 있다. "댓글을 삭제할까요?"로 확인한 뒤 지운다(CF-18-4). |
| BM-05-4 | 새 댓글 기준 | **마지막으로 댓글 관리를 연 뒤 달린 댓글**을 "새 댓글"로 센다. 내가 쓴 댓글은 세지 않는다. |
| BM-05-5 | 새 댓글 표시 | 새 댓글이 있으면 ① 왼쪽 메뉴 `댓글 관리` 옆, ② 화면 위쪽 사용자 메뉴, ③ 대시보드에 **숫자**를 보여 주고, 댓글 목록에서는 해당 댓글에 `NEW`를 붙인다. |
| BM-05-6 | 읽음 처리 | 댓글 관리 화면을 열면 새 댓글이 모두 "읽음"이 되어 숫자와 `NEW`가 사라진다. |
| BM-05-7 | 알림 범위 | 종 모양 알림 목록, 메일, 푸시 알림은 만들지 않는다. 숫자와 `NEW` 표시까지만 한다. `확인 필요` |
| BM-05-8 | 빈 상태 | 댓글이 없으면 "아직 달린 댓글이 없습니다"를 보여 준다. |

### 통계 (BM-06)

| ID | 요구사항 | 상세 |
|---|---|---|
| BM-06-1 | 기간 | **7일 / 30일** 중에서 고른다. 처음에는 30일이다. |
| BM-06-2 | 그래프 | 일별 **조회수와 방문자**를 한 그래프에, 일별 **댓글 수**를 다른 그래프에 보여 준다. 그래프에 마우스를 올리면 그날의 숫자가 보인다. |
| BM-06-3 | 조회수 | 글 상세를 열 때 센다. **같은 사람이 같은 글을 30분 안에 다시 열면 세지 않는다.** 로그인하지 않은 방문자도 센다. |
| BM-06-4 | 방문자 | 내 블로그를 찾아온 **사람 수**이다. 같은 사람은 **하루에 한 번만** 센다. |
| BM-06-5 | 조회수와 방문자의 차이 | 한 사람이 하루에 글 3개를 열면 방문자는 1, 조회수는 3이다. `확인 필요` |
| BM-06-6 | 하루의 기준 | 날짜는 **한국 시간 자정**에 바뀐다. |
| BM-06-7 | 글별 조회수 | 글마다 누적 조회수를 따로 센다. 글 관리 목록의 조회수와 대시보드의 인기 글에 쓴다. |
| BM-06-8 | 제외 | 어디서 들어왔는지(**유입 경로**), 시간대별·기기별 분석은 이번 범위에서 만들지 않는다. `확인 필요` |

| ID | 요구사항 | 상세 |
|---|---|---|
| BM-07-1 | 항목 | **블로그 이름**(필수, 1~30자)과 **소개**(0~200자)를 바꾼다. 소개 아래에 "n/200"으로 글자 수를 보여 준다. |
| BM-07-2 | 저장 | 저장하면 "저장했습니다"를 보여 주고 모든 화면에 바로 반영한다. 이름이 비어 있으면 "블로그 이름을 입력해 주세요"를 칸 아래에 보여 준다. |
| BM-07-3 | 데모 전용 | UI 시안에 있는 **"데모 데이터 초기화"** 버튼은 시안을 되돌리려는 것으로, **실제 서비스에는 만들지 않는다.** |

### 정하지 못한 것

- **마이페이지와 블로그 관리를 둘로 나누는 구조**: UI 시안은 이렇게 만들었지만 팀과 합의하지 않았습니다. (BM-01-3)
- **새 댓글 알림의 수준**: 지금은 숫자와 `NEW`까지입니다. 종 모양 알림 목록이나 메일 알림을 넣을지는 나중에 정합니다. (BM-05-7)
- **조회수와 방문자를 따로 세는 것**, **글 주인 본인이 자기 글을 열 때 조회수에 넣을지**를 정해야 합니다. (BM-06-3, 5)
- **유입 경로 통계**를 만들지 정합니다. (BM-06-8)
- **블로그를 여러 개 만들 수 있게 되면**, 관리 화면에서 블로그를 고르는 기능이 필요합니다. ([03-코어-블로그-글.md](03-코어-블로그-글.md)의 "정하지 못한 것")
- **대시보드의 누적 숫자**를 일별 기록의 합으로 구할지, 따로 누적 칸을 둘지는 ERD 단계에서 정합니다.

## 구현 방식

> 상태 표기: **확정**(정했음) / **가안**(바뀔 수 있음) / **미정**(아직 정하지 않음). 자세한 기술 설명과 그림은 [기술스택-아키텍처.md](../기술스택-아키텍처.md)에 있습니다.

> **작성 예정**입니다. 아래는 지금까지 정해 둔 방향이며, ERD 단계에서 표와 칸을 정리하면서 채웁니다.

| 영역 | 연결 ID | 구현 방식 | 상태 |
|---|---|---|---|
| 접근 검사 | BM-01-2 | 요청마다 로그인한 회원과 블로그 주인을 서버에서 비교한다. (그림: [기술스택-아키텍처.md 3장 D](../기술스택-아키텍처.md)) | 가안 |
| 일별 통계 | BM-02, BM-06 | **일별 통계 표**에 "블로그 + 날짜 + 조회수 + 방문자" 한 줄씩 쌓고, 그래프는 이 표를 읽어 그린다. 댓글 수는 댓글 표의 작성일로 센다 | 가안 |
| 조회수 중복 방지 | BM-06-3 | Redis에 "글 + 방문자 구분값" 키를 **30분 만료**로 저장한다. 키가 있으면 세지 않는다. 로그인하지 않은 방문자는 쿠키의 구분값으로 같은 사람을 판단한다 (그림: [3장 F](../기술스택-아키텍처.md)) | 가안 |
