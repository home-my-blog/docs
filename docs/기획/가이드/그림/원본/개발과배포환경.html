개발할 때와 배포할 때는 환경이 다릅니다

개발은 내 컴퓨터에서 하고, 배포는 학교가 무엇을 제공하는지 확인한 뒤에 정합니다

🧑‍💻 개발: 내 컴퓨터 (지금 하는 방식)

🖥️
화면 개발 서버 (Vite)터미널에서 실행합니다.
npm run dev
⚙️
Spring Boot 서버IntelliJ에서 실행합니다.
코드를 고치면 바로 확인할 수 있습니다.
📦
Docker Compose로 한 번에 켜는 상자들
PostgreSQL데이터·세션
Redis인증번호 등
MinIO이미지
$ docker compose up -d

🚀 배포: 환경 미정 (학교가 무엇을 제공하느냐에 따라 달라짐)

먼저 확인할 것: ① 배포까지 하나요? ② DB·Redis·MinIO를 학교가 제공하나요? ③ 앱을 올리는 곳은 어떤 형태인가요?
경우 1. 저장소 서버를 학교가 제공DB·Redis·MinIO 접속 정보(주소, 아이디, 비밀번호)만 받아서 설정에 적습니다. Compose는 내 컴퓨터에서만 씁니다.
경우 2. 앱 올리는 곳이 쿠버네티스우리 구조는 서버 한 대로 만들되, 올릴 때는 학교 양식(Dockerfile과 쿠버네티스 설정)을 따라야 할 수 있습니다.
경우 3. 서버 컴퓨터 한 대Compose에 서버와 화면까지 넣어서 한 대에 올립니다. 아무것도 제공되지 않으면 직접 서버를 구해야 합니다.
