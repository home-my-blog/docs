# 02. 블로그와 다이어리

> 한 사람에게 블로그가 하나 있고, 그 안에 글을 나눠 담는 다이어리가 여러 권 있어요.
> 동작 원리는 [원리/02-블로그와-다이어리.md](../원리/02-블로그와-다이어리.md)에 있어요.

## 한눈에

- 가입하면 블로그 하나("{닉네임}의 블로그")와 기본 다이어리 "일기장"이 저절로 생겨요. 블로그는 한 사람에 하나뿐이에요.
- 블로그 화면은 머리(이름·소개·책장), 왼쪽 다이어리 목록과 태그 모음, 가운데 소개·대표글·글 목록으로 되어 있어요.
- 주인은 블로그 이름, 한 줄 소개, 소개 글(about), 블로그 주제(분야)를 바꿀 수 있어요.
- 다이어리(코드에서는 분류, category)는 만들기, 이름, 소개, 표지 색 8가지, 공개 범위, 순서, 지우기를 할 수 있어요.
- 내 글 중 3개까지 대표글로 고정해서 블로그 첫 화면 위쪽에 보여 줄 수 있어요.
- 분야는 9개예요: 일상, 여행, 음식, 취미, 운동, 게임, 문화, 공부, 경제. 블로그와 다이어리에는 구독자 수가 보여요.

## 이렇게 써요

### 가입하면 블로그가 생겨요

- 가입을 마치는 순간 블로그가 만들어져요. 따로 "블로그 만들기" 버튼은 없어요.
- 처음 이름은 "{닉네임}의 블로그"예요. 예를 들어 닉네임이 수연이면 "수연의 블로그"가 돼요.
- 처음 블로그 주제는 "취미"예요. 다이어리는 "일기장" 한 권이 들어 있어요.
- 나중에 닉네임을 바꿔도 블로그 이름은 따라 바뀌지 않아요. 블로그 이름은 블로그 설정에서 따로 바꿔요.
- 한 사람이 블로그를 두 개 가질 수는 없어요.

### 블로그 화면 (`/blogs/{번호}`)

누구나(로그인 안 해도) 볼 수 있어요. 위에서 아래로 이렇게 보여요.

1. **배너 자리**: 지금은 회색 띠예요. 배너 사진 기능은 아직 없어요.
2. **머리**: 블로그 이름, 한 줄 소개, 그리고 "닉네임 · 다이어리 N권 · 글 N개 · 블로그 구독자 N명" 줄이 있어요.
   - 소개가 비어 있으면 주인에게만 "아직 소개가 없습니다. 소개 쓰기" 링크가 보여요.
   - 주인에게는 오른쪽에 `글쓰기`, `블로그 관리` 버튼이, 다른 사람에게는 블로그 구독 버튼이 있어요.
3. **책장**: 다이어리가 책 모양 표지로 줄지어 있어요. 표지마다 이름과 글 수가 붙어요. 누르면 그 다이어리 글만 봐요. 주인에게는 맨 끝에 `+ 새 다이어리` 책이 있어요.
4. **왼쪽 다이어리 목록**: "전체"와 다이어리 이름들, 각각의 글 수가 보여요. 구독자만 다이어리에는 "구독자 공개" 표, 비공개 다이어리에는 자물쇠가 붙어요.
5. **왼쪽 태그 모음**: 이 블로그 글에 많이 붙은 태그 12개까지, 많이 붙은 순서로 보여요. 누르면 그 태그가 붙은 글만 봐요. `✕ 태그 거르기 해제`로 돌아와요.
6. **가운데**: 첫 화면(다이어리·태그를 고르지 않고 1쪽)에서는 소개 상자와 대표글이 먼저 나오고, 그 아래에 글 목록이 있어요.

글 목록은 한 쪽에 10개씩이고, 정렬을 고를 수 있어요.

| 정렬 | 순서 |
| --- | --- |
| 최신순 (기본) | 쓴 시각이 새로운 글부터 |
| 인기순 | 인기 점수(조회 ×1 + 좋아요 ×5 + 댓글 단 사람 ×3 + 책갈피 ×4)가 높은 글부터 |
| 오래된 순 | 쓴 시각이 오래된 글부터 |

고른 다이어리, 태그, 정렬, 쪽 번호는 주소(`?category=`, `?tag=`, `?sort=`, `?page=`)에 남아요. 그래서 새로고침하거나 주소를 공유해도 같은 화면이 나와요.

**글 수는 보는 사람마다 달라요.** 주인은 비공개 글까지 모두 세고, 방문자는 자기가 볼 수 있는 글만 세요. 다이어리 목록도 마찬가지예요. 방문자에게는 비공개 다이어리가 아예 안 보여요.

### 블로그 소개

- 블로그 첫 화면 위쪽 소개 상자에 주인 닉네임, 주인 자기소개(내 정보의 bio), 블로그 소개 글(about)이 나와요.
- 소개 글이 4줄을 넘으면 접혀 있고, `더보기 ▾`로 펼치고 `접기 ▴`로 접어요.
- 소개 글과 자기소개가 둘 다 비어 있으면 방문자에게는 상자가 안 보이고, 주인에게만 "아직 소개 글이 없습니다. 소개 글 쓰기" 링크가 보여요.
- 예전 소개 주소 `/blogs/{번호}/about`로 들어오면 블로그 첫 화면으로 옮겨 가요. 소개 전용 페이지는 따로 없어요.

### 블로그 설정 (블로그 관리 > 설정, 주인만)

| 칸 | 규칙 |
| --- | --- |
| 블로그 이름 | 꼭 넣어야 해요. 앞뒤 공백을 빼고 1~30자 |
| 소개 (한 줄 소개) | 비워도 돼요. 200자까지. 블로그 머리에 보여요 |
| 소개 글 (about) | 비워도 돼요. 5000자까지. 첫 화면 소개 상자에 보여요. 줄바꿈이 그대로 보여요 |
| 주제 | 분야 9개 중 하나 |

- 바꾼 칸만 서버로 보내요. 아무것도 안 바꾸면 `저장` 버튼이 눌리지 않아요.
- 저장하지 않고 다른 화면으로 가려 하면 "저장하지 않은 내용이 있습니다. 나갈까요?" 확인 창이 떠요.
- 블로그 주제는 이런 곳에 쓰여요: 분야 화면의 블로그 목록과 블로그 수, 블로그 카드의 주제 표, 블로그 검색(주제 이름으로도 찾아요), 블로그를 볼 때 머리 메뉴의 분야 강조, 글쓰기에서 분야를 고르지 않았을 때의 기본값.

### 다이어리 만들기와 관리 (블로그 관리 > 다이어리 관리, 주인만)

- **만들기**: 이름을 넣고 `추가`. 새 다이어리는 목록 맨 아래에 붙고, 표지 색은 8가지 색 중에서 차례대로 정해져요.
- **이름 바꾸기**: `이름 변경`을 누르고 고친 뒤 `저장`(Enter) 또는 `취소`(Esc).
- **순서 바꾸기**: ▲ ▼ 버튼으로 한 칸씩 위아래로 옮겨요. 맨 위의 ▲, 맨 아래의 ▼는 눌리지 않아요. 바꾼 순서가 책장과 왼쪽 목록에 그대로 나와요.
- **지우기**: `삭제`를 누르고 확인하면 지워져요. 다만 아래 두 경우는 지울 수 없어요.
  - 기본 다이어리("기본" 표가 붙은 것, 처음엔 "일기장"): "기본 다이어리는 삭제할 수 없습니다"
  - 글이 하나라도 든 다이어리: "이 다이어리에 글이 N개 있어 삭제할 수 없습니다. 글을 다른 다이어리로 옮긴 뒤 삭제해 주세요"

**글은 어디로 가나요?** 다이어리를 지울 때 글이 저절로 다른 곳으로 옮겨지지 않아요. 글이 있으면 지우기 자체가 막혀요. 그러니 먼저 글을 옮기거나 지운 다음 빈 다이어리를 지워요. 비공개 글도 글 수에 들어가요.

### 다이어리 설정 창

블로그 화면에서 내 다이어리를 고르면 위에 다이어리 머리가 나오고, 거기 `다이어리 설정` 버튼이 있어요.

| 칸 | 규칙 |
| --- | --- |
| 이름 | 꼭 넣어야 해요. 1~20자. 한 블로그 안에서 겹칠 수 없어요(영문 대소문자는 같은 이름으로 봐요) |
| 소개 | 비워도 돼요. 100자까지. 다이어리 머리와 책장 표지의 말풍선에 보여요 |
| 표지 색 | 8가지 중 하나 |
| 공개 범위 | 공개 / 구독자만 / 비공개 |

- 같은 창에서 상점에서 산 표지 스티커도 붙여요(스티커는 상점 문서에서 다뤄요).
- 공개 범위를 비공개로 바꾸면 "비공개로 바꾸면 이 다이어리의 글은 나만 볼 수 있습니다. 바꿀까요?"를 한 번 더 물어요.
- 구독자가 있는 다이어리면 "지금 구독자 N명, 비공개로 바꾸면 구독이 모두 해제돼요"라고 미리 알려 줘요.

### 다이어리 공개 범위

공개 범위는 **다이어리 한 권 단위**로 정해요. 글에도 따로 공개 범위가 있어서, 둘 다 통과해야 글이 보여요.

| 다이어리 | 누가 보나 |
| --- | --- |
| 공개 | 누구나. 글의 공개 범위에 따라 달라져요 |
| 구독자만 | 그 블로그나 그 다이어리를 구독한 사람과 주인. 메인·검색·인기 글·분야 화면에는 안 나와요 |
| 비공개 | 주인만. 글을 공개로 써도 이 다이어리 안에 있으면 주인만 봐요 |

방문자에게는 볼 수 없는 다이어리가 목록에서 아예 빠져요.

### 다이어리 머리와 편집 모드

다이어리를 고르면 글 목록 위에 표지, 이름, 소개, "글 N개 · 구독자 N명"이 나와요.

- 주인에게는 `이 다이어리에 쓰기`, `다이어리 설정`, `편집` 버튼이 있어요.
- 다른 사람에게는 다이어리 구독 버튼이 있어요.
- **편집 모드**: 지금 쪽의 글을 체크해서 다른 다이어리로 한꺼번에 옮기거나 한꺼번에 지워요. 옮겨도 글의 수정 시각은 바뀌지 않아요. 내 블로그 다이어리로만 옮길 수 있어요.

### 대표글

- 글 화면에서 글쓴이에게만 `📌 대표글로 고정` 버튼이 보여요. 다시 누르면 `대표글 해제`예요.
- 블로그마다 **3개까지** 고정해요. 4번째를 고정하면 "대표글은 3개까지 고정할 수 있습니다. 다른 글의 고정을 먼저 풀어 주세요"가 나와요.
- 블로그 첫 화면 위쪽 "대표글" 칸에 **고정한 순서대로** 나와요. 카드에 사진, 다이어리 이름, 제목, 미리보기가 보여요.
- 방문자에게는 자기가 볼 수 있는 대표글만 보여요. 비공개 글을 고정해 두면 주인에게만 보여요.

### 분야 (topics)

지금 분야는 9개예요. 화면에서는 "분야"라고도 하고 "주제"라고도 불러요(블로그 설정 칸 이름은 "주제").

| 순서 | 분야 | 코드 |
| --- | --- | --- |
| 1 | 일상 | daily |
| 2 | 여행 | travel |
| 3 | 음식 | food |
| 4 | 취미 | hobby |
| 5 | 운동 | exercise |
| 6 | 게임 | game |
| 7 | 문화 | culture |
| 8 | 공부 | study |
| 9 | 경제 | money |

- 블로그에 주제가 하나 있고, 글마다 분야가 따로 하나 있어요. 홈의 분야 탭과 분야 화면의 글은 **글의 분야**로 나눠요.
- 분야는 그동안 이렇게 바뀌었어요.
  - 처음(V1): 여행, 음식, 취미, 운동, 개발 5개. 분야는 블로그에만 있었어요.
  - V8: 글마다 분야를 골라요. 있던 글은 블로그 주제로 채웠어요.
  - V9: 19개로 늘렸어요.
  - V10: 10개로 줄였어요. 빠진 분야의 글과 블로그는 "기타"로 옮겼어요.
  - V11: 지금의 9개. 개발은 공부로, 책·영화·드라마는 문화로, 기타는 일상으로 옮겼어요. 임시저장 글은 분야를 비웠어요.

### 구독자 수

- 블로그 머리: "블로그 구독자 N명"
- 다이어리 머리: "글 N개 · 구독자 N명"(이 다이어리만 구독한 사람 수)
- 탈퇴 신청한 회원은 구독자 수에서 빠져요. 구독하기·취소하기 자체는 구독 문서에서 다뤄요.

## 규칙과 숫자

| 항목 | 값 | 바꾸는 곳 |
| --- | --- | --- |
| 한 사람의 블로그 수 | 1개 | DB 제약 `uk_blogs_owner_id` (V1, V2) |
| 처음 블로그 이름 | "{닉네임}의 블로그" | `BlogService.createFor` |
| 처음 블로그 주제 | hobby(취미) | `myblog.blog.default-topic` |
| 기본 다이어리 이름 | 일기장 | `myblog.blog.default-category-name` |
| 블로그 이름 | 1~30자 | `myblog.blog.name-max` |
| 블로그 한 줄 소개 | 0~200자 | `myblog.blog.description-max` |
| 블로그 소개 글(about) | 0~5000자 | `myblog.blog.about-max` |
| 소개 글 접힘 | 4줄 넘으면 | `frontend/src/styles/pages.css` (`.intro__body`) |
| 다이어리 이름 | 1~20자, 블로그 안에서 겹치면 안 됨 | `myblog.blog.category-name-max` |
| 다이어리 소개 | 0~100자 | `myblog.blog.category-description-max` |
| 표지 색 | 8가지 | `myblog.blog.color-count`, 색 값은 `frontend/src/lib/format.ts` (`CATEGORY_COLORS`) |
| 블로그 태그 모음 | 12개 | `myblog.blog.blog-tags` |
| 블로그 글 목록 한 쪽 | 10개 | `myblog.post.page-size` |
| 대표글 | 블로그마다 3개 | `myblog.post.pin-limit` |
| 분야 | 9개 | `topics` 표 (Flyway 마이그레이션 V11) |

글자 수는 앞뒤 공백을 뺀 뒤 한 글자씩 세요. 한글 한 글자, 이모지 한 개가 모두 1자예요.

## 알아 두면 좋은 것

- 블로그를 만들거나 지우는 버튼은 없어요. 블로그는 가입할 때 생기고, 탈퇴 보관 기간(30일)이 지나야 지워져요. 탈퇴 신청한 사람의 블로그는 없는 블로그로 보여요.
- 남의 블로그를 고치려 하면 "없는 블로그"로 답해요. 남의 블로그가 있다는 것조차 알려 주지 않기 위해서예요.
- 다이어리를 지울 때 글을 다른 다이어리로 옮겨 주는 기능은 없어요. 지우기가 막히는 것이 정상이에요.
- 기본 다이어리는 이름은 바꿀 수 있지만 지울 수는 없어요. 기본 다이어리는 블로그마다 딱 하나예요.
- 예전 기본 다이어리 이름은 "미분류"였어요. V20에서 "일기장"으로 바꿨어요. 이미 "일기장"이라는 다이어리가 따로 있던 블로그는 이름이 겹치지 않게 "미분류"를 그대로 두었어요.
- 다이어리 관리 화면 아래 안내에는 "글은 글 수정에서 옮길 수 있다"고 적혀 있지만, 블로그 화면 다이어리 머리의 `편집`으로 여러 글을 한꺼번에 옮길 수도 있어요.
