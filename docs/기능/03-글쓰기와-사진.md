# 03. 글쓰기와 사진

> 마크다운으로 글을 쓰고, 사진을 넣고, 임시저장하고, 고치고 지우는 기능이에요.
> 동작 원리는 [원리/03-글쓰기와-사진.md](../원리/03-글쓰기와-사진.md)에 있어요.

## 한눈에

- **글쓰기**: 제목, 본문(마크다운), 다이어리, 분야, 공개 범위(공개 / 구독자만 / 비공개), 태그 5개를 정해서 올려요.
- **마크다운 표시**: 본문은 마크다운 그대로 저장하고, 화면이 안전한 것만 골라서 그려요.
- **임시저장**: 새 글을 쓸 때 20개까지 저장해 두고, 60초마다 자동으로도 저장돼요.
- **수정·삭제**: 내 글을 고치거나 지워요. 다이어리 편집 모드에서는 여러 글을 한꺼번에 옮기거나 지워요.
- **사진**: jpg·png·gif·webp를 한 장 5MB, 글마다 10장까지 넣고, 그중 하나를 대표 사진으로 골라요.

## 이렇게 써요

### 글쓰기 화면 열기

- 로그인한 회원만 쓸 수 있어요. 글은 **내 블로그에만** 쓸 수 있어요.
- 새 글은 `/write`, 고치기는 `/posts/{글 번호}/edit` 화면이에요.
- 다이어리 화면의 "이 다이어리에 쓰기"로 들어오면 주소가 `/write?category=번호`가 되고, 그 다이어리가 미리 골라져 있어요.

### 다이어리와 분야 고르기

- **다이어리**는 꼭 골라야 해요. 목록에는 내 블로그의 다이어리만 나와요. 구독자만·비공개 다이어리는 이름 뒤에 표시가 붙어요.
- 새 글을 열면 다이어리가 이 순서로 미리 골라져요.
  1. 주소에 `?category=번호`가 있으면 그 다이어리
  2. 없으면 **마지막으로 쓴 글의 다이어리**
  3. 글을 한 번도 안 썼으면 기본 다이어리("일기장")
- **분야**는 9개 중 하나를 골라요(일상, 여행, 음식, 취미, 운동, 게임, 문화, 공부, 경제). 처음에는 블로그 분야로 골라져 있어요. 비워 두면 서버가 블로그 분야로 채워요.

### 공개 범위 정하기

- **공개 / 구독자만 / 비공개** 세 버튼 중 하나를 눌러요. 고르지 않으면 공개예요.
- "구독자만" 버튼에 마우스를 올리면 "이 블로그나 다이어리를 구독한 사람만"이라고 알려 줘요.
- 구독자만이나 비공개에서 **공개로 바꿀 때**는 "공개로 바꾸면 누구나 볼 수 있습니다"라고 한 번 더 물어봐요.
- 누가 어떤 글을 볼 수 있는지는 볼 수 있는 범위를 다루는 문서에서 자세히 다뤄요.

### 제목과 본문 쓰기

- 제목은 꼭 써야 하고 100자까지예요. 제목 칸 아래에 `지금 글자 수/100`이 보여요.
- 본문도 꼭 써야 하고 10,000자까지예요. 아래쪽에 `1,234자 / 10,000`처럼 보이고, 넘으면 빨갛게 바뀌어요.
- 본문은 **마크다운**(기호로 모양을 정하는 글쓰기 방식. `# 제목`, `**굵게**`, `- 목록` 같은 것)으로 써요.
- "작성" 탭과 "미리보기" 탭이 있어요. 미리보기는 실제 글 화면과 같은 방식으로 그려 줘요.
- 제목이나 본문이 비어 있는데 올리면, 그 칸으로 커서를 옮기고 안내 문구를 보여 줘요.

### 태그 달기

- 태그 칸에 쓰고 **Enter**나 **쉼표**를 누르면 태그가 붙어요. 칸을 벗어날 때도 붙어요.
- 앞에 붙인 `#`은 지워요. `#여행`이라고 써도 `여행`으로 저장돼요.
- 한 개에 1~15자, 띄어쓰기와 쉼표는 안 돼요. 글마다 5개까지예요.
- 대소문자만 다른 같은 태그는 하나로 봐요(`Java`와 `java`). "이미 붙인 태그입니다"라고 알려 줘요.
- 칸이 비어 있을 때 Backspace를 누르면 마지막 태그가 지워져요. 태그 옆 ×로도 지워요.
- 태그 칸에 글자를 남긴 채 올려도, 규칙에 맞으면 그 태그까지 붙여서 올려요.

### 사진 넣기

1. "이미지 올리기"를 누르고 사진을 골라요. 올리는 동안 버튼이 "올리는 중…"으로 바뀌어요.
2. 다 올라가면 커서 자리에 `[📷 사진 1]` 같은 **이름표**가 들어가요. 저장될 때는 진짜 마크다운 `![](주소)`로 바뀌어요.
3. 본문 아래에 **사진 줄**이 생겨요. `올린 사진 2/10`처럼 몇 장 넣었는지 보여요.
   - 사진을 누르면 커서 자리에 그 사진을 **다시 넣어요**.
   - **☆**을 누르면 그 사진이 **대표 사진(★)** 이 돼요. 다시 누르면 풀려요.
   - **×**를 누르면 본문에서 그 사진의 이름표를 모두 빼요.
4. 사진 줄에는 **지금 본문에 들어 있는 사진만** 보여요. 이름표를 손으로 지워도 사진 줄에서 사라져요.

올릴 수 없는 경우에는 이렇게 알려 줘요.

- jpg·png·gif·webp가 아니거나 5MB를 넘으면: "이미지는 5MB 이하의 jpg, png, gif, webp만 올릴 수 있습니다"
- 본문에 이미 10장이 있으면: "이미지는 글 하나에 10장까지 올릴 수 있습니다"

### 대표 사진과 목록 미리보기

- 대표 사진을 고르면 글 화면 맨 위에 그 사진이 크게 나와요.
- 목록에서는 이렇게 보여요.
  - 대표 사진이 있으면 그 사진
  - 없으면 본문의 **첫 번째 사진**
  - 사진이 아예 없으면
    - 인기 글·추천 글 카드처럼 사진 칸이 꼭 있는 곳은 **연한 회색 줄노트** 무늬
    - 분야별 글·전체 글·검색 결과 같은 가로 목록은 **사진 칸 없이** 글만
- 대표 사진을 안 골랐을 때 글 화면 맨 위에는 사진이 따로 나오지 않아요. 첫 사진 미리보기는 목록에서만 써요.

### 올리기

- "올리기"(수정 화면에서는 "저장")를 누르면 글이 저장되고 그 글 화면으로 가요.
- 저장하는 동안 버튼이 "저장하는 중…"으로 바뀌고, 여러 번 눌러도 한 번만 보내요. 사진을 올리는 중에도 누를 수 없어요.
- 저장에 실패해도 쓴 내용은 그대로 남아요. 칸마다 무엇이 잘못됐는지 보여 줘요.
- 공개 글을 새로 올리면 잉크가 쌓여요(자세한 건 06 문서).

### 저장하지 않고 나가기

- 고친 내용이 있는데 다른 화면으로 가거나 창을 닫으려 하면 "저장하지 않은 내용이 있습니다. 나갈까요?"라고 물어봐요.
- "취소" 버튼은 이전 화면으로 돌아가요. 이때도 같은 질문이 나와요.

### 임시저장

새 글을 쓸 때만 있어요. 이미 올린 글을 고칠 때는 임시저장 버튼이 없어요.

- **직접 저장**: "임시저장" 버튼을 눌러요. 제목이나 본문 중 하나만 있어도 돼요. 둘 다 비면 "제목이나 본문을 입력하면 임시저장할 수 있습니다"라고 알려 줘요.
- **자동 저장**: 60초마다, 마지막 저장 뒤에 바뀐 게 있을 때만 저장돼요. 바뀐 게 없거나 둘 다 비어 있으면 건너뛰어요.
- 저장되면 위쪽에 "임시저장 14:05" 또는 "자동 임시저장 14:06"처럼 시각이 나와요.
- 처음 저장하면 주소가 `/write?draft=번호`로 바뀌어요. 새로고침해도 그 글을 이어서 쓸 수 있어요. 그 뒤로는 같은 임시저장 글에 덮어써요.
- **불러오기**: 위쪽 "임시저장 글 N"을 누르면 목록 창이 떠요. 최근에 저장한 것부터 제목, 본문 앞부분, 저장 시각이 보여요. 누르면 그 글을 이어서 써요. 제목이 없으면 "(제목 없음)"으로 보여요.
- **지우기**: 목록 창에서 "삭제"를 누르고 한 번 더 확인해요.
- 한 사람당 **20개**까지예요. 넘으면 "임시저장은 20개까지 할 수 있습니다. 쓰지 않는 임시저장 글을 지워 주세요"라고 알려 줘요.
- 임시저장 글을 이어 쓰다가 **올리면** 그 임시저장 글은 지워져요.
- 임시저장에는 제목, 본문, 다이어리, 분야, 공개 범위, 태그, 사진, 대표 사진이 모두 남아요.

### 글 고치기

- 글 화면의 "수정" 버튼으로 들어가요. 글쓴이만 볼 수 있어요. 다른 사람이 주소를 쳐서 들어오면 "없는 글"로 보여요.
- 쓸 때와 같은 화면, 같은 규칙이에요. 이미 넣은 사진은 사진 줄에 그대로 나와요.
- **수정 시각**은 제목·본문·다이어리·분야·공개 범위 중 하나라도 실제로 바뀐 때만 바뀌어요. 태그나 대표 사진만 바꾸면 그대로예요.
- 본문에서 뺀 사진은 글과의 연결이 풀리고, 나중에 정리 작업이 지워요.

### 글 지우기

- 글 화면의 "삭제" 버튼, 또는 블로그 관리 > 글 관리에서 지워요. "삭제하면 되돌릴 수 없습니다. 삭제할까요?"라고 확인해요.
- 글쓴이만 지울 수 있어요.
- 글과 함께 댓글, 좋아요, 태그 연결, 책갈피, 사진(기록과 파일)이 모두 지워져요.

### 여러 글 한꺼번에 옮기기·지우기

블로그 주인이 다이어리 화면에서 **편집 모드**를 켜면 할 수 있어요.

- 지금 보이는 페이지의 글에 체크하거나 "모두 선택"을 눌러 골라요.
- **옮기기**: 옮길 다이어리를 고르고 확인하면 "글 3개를 옮겼습니다"처럼 알려 줘요. 옮겨도 수정 시각은 그대로예요.
- **지우기**: "고른 글 N개를 삭제할까요? 댓글과 좋아요도 함께 지워지고 되돌릴 수 없습니다"를 확인하면 지워요.
- 고른 글 중 하나라도 내 블로그 글이 아니면 전부 거절해요.

## 규칙과 숫자

| 항목 | 값 | 바꾸는 곳 |
| --- | --- | --- |
| 제목 길이 | 1~100자 | `myblog.post.title-max` |
| 본문 길이 | 1~10,000자 | `myblog.post.body-max` |
| 목록·임시저장 목록의 본문 앞부분 | 100자 + "…" | `myblog.post.excerpt-length` |
| 공개 범위 | PUBLIC(공개) / SUBSCRIBERS(구독자만) / PRIVATE(비공개), 기본 PUBLIC | `PostCommandService` |
| 태그 개수 | 글마다 5개 | `myblog.tag.max-per-post` |
| 태그 길이 | 1~15자, 띄어쓰기·쉼표 불가 | `myblog.tag.max-length` |
| 임시저장 개수 | 회원마다 20개 | `myblog.draft.max-per-member` |
| 자동 임시저장 간격 | 60초 (0이면 끔) | `myblog.draft.autosave-interval` |
| 사진 한 장 크기 | 5MB (5,242,880바이트) | `myblog.image.max-bytes` |
| 서버가 받는 파일 한 개 / 요청 전체 | 6MB / 7MB | `spring.servlet.multipart.max-file-size`, `max-request-size` |
| 글마다 사진 | 10장 | `myblog.image.max-per-post` |
| 사진 종류 | jpeg, png, gif, webp | `ImageService.detect` |
| 사진 저장 방식 | 디스크(`disk`), 고를 수 있는 것은 `s3` | `myblog.image.storage` (`MYBLOG_IMAGE_STORAGE`) |
| 사진 저장 폴더 | 기본 `./data/images`, 도커 안에서는 `/data/images` | `myblog.image.disk-path` (`MYBLOG_IMAGE_DISK_PATH`) |
| 사진 응답 캐시 | 30일 | `ImageController` |
| 글에 안 붙은 사진 보관 | 올린 뒤 24시간 | `myblog.image.orphan-ttl` |
| 정리 작업 간격 | 1시간마다 (서버 켜고 1분 뒤 처음) | `ImageService.cleanOrphans` |

글자 수는 서버에서 코드 포인트(한글·이모지 한 글자를 1로 세는 방식)로 세요.

## 알아 두면 좋은 것

- **사진 주소는 누구나 열 수 있어요.** 비공개 글에 넣은 사진도 주소(`/api/images/...`)를 알면 로그인 없이 보여요.
- **글마다 10장 검사는 올릴 때가 아니라 글을 저장할 때** 서버가 해요. 화면은 본문에 이미 10장이 있으면 더 못 올리게 막아요.
- 사진 종류는 **파일 이름이 아니라 파일 내용**으로 확인해요. 이름만 `.jpg`로 바꾼 파일은 거절돼요.
- 올린 사진의 원래 파일 이름은 남기지 않아요. 서버가 새 이름을 지어 줘요.
- 사진 이름표의 번호(`사진 1`, `사진 2`)는 **이번에 올린 순서**예요. 사진을 빼도 다른 사진 번호는 바뀌지 않아요.
- 사진을 올려 놓고 글을 안 올리면, 그 사진은 **올린 지 24시간이 지난 뒤** 매시간 도는 정리 작업이 지워요. 임시저장 글에 들어 있는 사진은 지우지 않아요.
- 고칠 때 본문에서 뺀 사진은 "뺀 때부터 24시간"이 아니라 "**처음 올린 때부터 24시간**"을 기준으로 지워요. 오래전에 올린 사진이면 다음 정리 때 바로 지워져요.
- 본문에는 원시 HTML(`<div>`, `<script>` 같은 태그)을 써도 화면에 그려지지 않아요.
- 본문의 사진은 `http(s)://` 주소나 이 사이트에 올린 사진(`/api/images/...`)만 보여요. 다른 형태의 주소는 빈칸이 돼요.
- 다른 사이트로 가는 링크는 새 탭에서 열려요.
- 임시저장은 **새 글에서만** 돼요. 이미 올린 글을 고치다가 임시로 저장해 둘 수는 없어요.
- 임시저장 글에 고른 다이어리를 나중에 지웠으면, 불러올 때 다이어리가 비어 있다가 기본 고르기 순서대로 채워져요.
- 한꺼번에 옮기기·지우기는 **지금 보이는 페이지의 글**만 고를 수 있어요.
- 대표글(블로그 위쪽 고정) 기능은 이 문서에서 다루지 않아요.
