# 01. 회원과 로그인

> 이메일 인증번호로 가입하고, 이메일과 비밀번호 또는 카카오 · 구글 계정으로 로그인하고, 내 정보에서 계정을 관리하는 기능이에요.
> 동작 원리는 [원리/01-회원과-로그인.md](../원리/01-회원과-로그인.md)에 있어요.

## 한눈에

- 회원가입: 닉네임과 이메일을 넣고, 이메일로 받은 6자리 인증번호를 확인한 뒤 비밀번호를 정해요. 가입하면 내 블로그가 하나 생겨요.
- 로그인과 로그아웃: 이메일과 비밀번호로 로그인해요. 5번 틀리면 10분 동안 잠겨요. 로그인은 7일 유지되고, 쓸 때마다 다시 7일로 늘어나요.
- 카카오 · 구글로 시작하기(v1.8.0): 로그인 창의 버튼으로 카카오나 구글에서 로그인하고 돌아와요. 처음이면 닉네임만 정하면 가입이 끝나요.
- 가입한 방법으로만 로그인(v1.9.0): 계정은 가입한 방법(이메일, 카카오, 구글 중 하나)으로만 로그인해요. 같은 이메일이어도 다른 방법의 계정과 자동으로 합치지 않고, 어느 방법으로 로그인하면 되는지 알려 줘요.
- 비밀번호 찾기: 인증번호를 확인한 뒤 새 비밀번호를 정해요. 바꾸면 모든 기기에서 로그아웃돼요. 카카오 · 구글로 가입한 계정은 비밀번호가 없어서, 인증번호 대신 어느 방법으로 로그인하면 되는지 메일로 알려 줘요(v1.9.0).
- 내 정보(`/me`): 닉네임, 소개, 비밀번호를 바꿔요. 비밀번호를 바꾸면 다른 기기만 로그아웃돼요. 카카오 · 구글로 가입한 회원은 비밀번호 변경이 보이지 않고(v1.8.1), 탈퇴할 때 비밀번호 대신 가입한 카카오 · 구글 계정으로 다시 로그인해 본인을 확인해요(v1.9.1).
- 탈퇴와 복구: 탈퇴하면 30일 동안 보관하고, 그 안에 로그인하면 되살릴 수 있어요. 소셜 가입 회원은 가입한 카카오 · 구글 계정으로 로그인하면 복구할지 물어요(v1.9.2). 30일이 지나면 새벽 4시 40분에 지우고 익명화(누군지 알 수 없게 바꾸기)해요.
- 권한: 글 읽기는 누구나, 쓰기와 바꾸기는 로그인한 회원만 할 수 있어요.

## 이렇게 써요

### 회원가입 (방문자)

1. 머리글의 로그인 버튼을 누르면 `로그인 | 회원가입` 탭이 있는 창이 떠요. 회원가입 탭을 골라요.
2. 닉네임과 이메일을 넣고 **인증번호 받기**를 눌러요.
   - 이때 서버가 먼저 이미 가입된 이메일인지, 닉네임이 겹치는지 확인해요. 겹치면 그 칸 아래에 "이미 가입된 이메일입니다" 같은 문구가 떠요.
   - 카카오 · 구글로 가입한 이메일이면 "카카오로 가입한 이메일입니다. 카카오로 로그인해 주세요"(구글이면 "구글로 …")가 떠요(v1.9.0).
   - 탈퇴하고 아직 30일이 안 지난 이메일이면 "탈퇴 처리 중인 이메일입니다. 로그인하면 복구할 수 있고, 보관 기간이 지나면 새로 가입할 수 있습니다"가 떠요.
3. 메일로 받은 6자리 번호를 넣고 **확인**을 눌러요. 맞으면 "이메일 인증이 완료되었습니다"가 뜨고 이메일 칸이 잠겨요. 다른 이메일로 바꾸고 싶으면 **이메일 변경**을 누르면 인증이 취소돼요.
4. 비밀번호와 비밀번호 확인을 넣어요. 입력하는 동안 규칙을 지켰는지 바로 보여 줘요.
5. **가입하기**를 누르면 가입이 끝나요. 창이 로그인 탭으로 바뀌고 "가입이 완료되었습니다. 로그인해 주세요"가 보여요. 가입한다고 바로 로그인되지는 않아요.

가입하면 블로그가 저절로 하나 생겨요. 이름은 "닉네임의 블로그", 분야는 취미, 다이어리는 "일기장" 하나가 들어 있어요.

### 인증번호

- 번호는 영문 대문자와 숫자 6자예요. 헷갈리는 O, 0, I, 1은 쓰지 않아요. 소문자로 넣어도 되고, 앞뒤 공백은 무시해요.
- 받은 뒤 10분 동안만 쓸 수 있어요.
- 다시 받기는 1분에 한 번, 하루(한국 날짜 기준)에 5번까지예요. 너무 빨리 누르면 "잠시 뒤에 다시 요청해 주세요", 5번을 넘기면 "오늘은 더 이상 인증번호를 보낼 수 없습니다"가 떠요.
- 새 번호를 받으면 예전 번호, 틀린 횟수, 인증 완료 표시가 모두 없어져요.
- 틀린 번호를 5번 넣으면 그 번호는 버려져요. "인증번호 입력 횟수를 초과했습니다. 인증번호를 다시 받아 주세요"가 뜨고, 새로 받아야 해요.
- 맞게 넣으면 30분 안에 가입(또는 비밀번호 변경)을 끝내야 해요. 넘기면 "인증 유효 시간이 지났습니다"가 뜨고 인증을 다시 해야 해요.
- 가입용 번호와 비밀번호 찾기용 번호는 따로예요. 가입 인증으로 비밀번호를 바꿀 수는 없어요.
- **메일 모드에 따라 달라요.** 메일 모드가 `log`(서버 로그에만 찍기)면 진짜 메일이 가지 않아서, **가입** 인증번호만 화면 문구 끝에 "(임시 인증번호: XXXXXX)"로 같이 보여요. `smtp`면 메일로만 가고 화면에는 보이지 않아요.
- **비밀번호 찾기 번호는 어떤 모드에서도 화면에 보이지 않아요(v1.7.1).** 예전에는 `log` 모드에서 이 번호도 응답에 실려서, 남의 이메일만 알면 그 사람 비밀번호를 바꿀 수 있었어요. 이제 이 번호는 메일(또는 서버 로그)로만 가요.
- 운영 서버는 GitHub Secrets에 `SMTP_HOST`가 있으면 `smtp`, 없으면 `log` 모드로 떠요. 자세한 건 [08. 운영과 배포](08-운영과-배포.md)에 있어요.

### 입력 규칙

| 항목 | 규칙 |
| --- | --- |
| 이메일 | 앞뒤 공백을 빼고 소문자로 바꿔서 써요. `글자@글자.글자` 모양, 254자까지. 가입 뒤에는 바꿀 수 없어요 |
| 닉네임 | 한글·영문·숫자만, 2~10자. 영문 대소문자만 다르면 같은 닉네임으로 봐요(`Suyeon`과 `suyeon`은 겹침) |
| 비밀번호 | 8~64자. 영문, 숫자, 특수문자(`!@#$%^&*()_+-=`)를 하나 이상씩 꼭 넣어요. 공백, 한글, 그 밖의 특수문자는 쓸 수 없어요 |
| 비밀번호 확인 | 비밀번호와 똑같아야 해요 |

비밀번호는 그대로 저장하지 않고, 되돌릴 수 없게 섞은 값(BCrypt 해시)만 저장해요. 운영하는 사람도 원래 비밀번호를 볼 수 없어요.

### 로그인 (방문자)

1. 로그인 창에 이메일과 비밀번호를 넣고 **로그인**을 눌러요.
2. 맞으면 창이 닫히고, 로그인 창을 띄우게 만든 동작(예: 좋아요 누르기)이 있었다면 이어서 실행돼요.
3. 틀리면 이메일이 틀렸든 비밀번호가 틀렸든 똑같이 "이메일 또는 비밀번호가 올바르지 않습니다"가 떠요. 가입된 이메일인지 알아내지 못하게 하려는 거예요.
4. 카카오 · 구글로 가입한 계정의 이메일을 넣으면 비밀번호와 관계없이 로그인하지 않고 "카카오로 가입한 계정입니다. 카카오로 로그인해 주세요"(구글이면 "구글로 …")가 떠요(v1.9.0).

잠금 규칙도 있어요.
- 비밀번호를 5번 연속 틀리면 10분 동안 잠겨요. "로그인 시도가 5회 실패해 잠겼습니다. N분 뒤에 다시 시도해 주세요"가 떠요.
- 잠긴 동안은 맞는 비밀번호를 넣어도 로그인이 안 돼요.
- 로그인에 성공하면 틀린 횟수는 0으로 돌아가요. 잠금이 풀린 뒤에도 0부터 다시 세요.
- 내 정보에서 비밀번호를 바꾸거나 탈퇴할 때 "현재 비밀번호"를 틀려도 같은 횟수에 더해져요.

로그인이 필요한 일을 로그인 없이 하려고 하면 로그인 창이 저절로 떠요. 로그인이 끝나면 하려던 일을 이어서 해요.

### 카카오 · 구글로 시작하기 (방문자)

v1.8.0에서 생겼어요. 서버에 그 제공자의 키가 설정되어 있을 때만 버튼이 보여요. 둘 다 없으면 로그인 창에 "또는" 줄과 버튼이 아예 안 보여요.

1. 로그인 창 아래 "또는" 줄 밑의 **카카오로 시작하기** 또는 **구글로 시작하기**를 눌러요.
2. 카카오나 구글 화면에서 로그인하고 정보 제공에 동의해요. 카카오는 닉네임과 이메일, 구글은 이름과 이메일을 받아요.
3. 사각으로 돌아오면 경우에 따라 이렇게 돼요.

| 경우 | 결과 |
| --- | --- |
| 이 카카오 · 구글 계정으로 가입한 회원이 있음 | 바로 로그인돼요 |
| 처음 보는 이메일 | 닉네임을 정하는 화면(`/social/signup`)으로 가요 |
| 같은 이메일이 이메일로 가입돼 있음(v1.9.0) | 연결하지 않고 로그인하지 않아요. 홈에서 "이메일로 가입한 계정입니다. 이메일과 비밀번호로 로그인해 주세요"가 떠요 |
| 같은 이메일이 다른 카카오 · 구글 계정으로 가입돼 있음(v1.9.0) | 연결하지 않고 로그인하지 않아요. 홈에서 "카카오로 가입한 이메일입니다. 카카오로 로그인해 주세요"(구글이면 "구글로 …")가 떠요 |
| 이 계정으로 가입한 회원이 탈퇴 신청한 상태(v1.8.1) | 탈퇴 신청을 취소하고 바로 로그인돼요. 홈에서 "탈퇴 신청을 취소하고 계정을 복구했어요. 다시 만나서 반가워요!"가 떠요 |
| 같은 이메일로 이메일 가입한 회원이 탈퇴 신청한 상태 | 로그인하지 않고 홈에서 "탈퇴 신청한 계정입니다. 복구하려면 이메일과 비밀번호로 로그인해 주세요"가 떠요 |
| 이메일을 받지 못함(동의 안 함, 제공자가 인증하지 않은 이메일) | 홈에서 "이메일 정보를 받지 못해 로그인할 수 없습니다. 이메일 제공에 동의하고 다시 시도해 주세요"가 떠요 |
| 동의를 취소했거나 그 밖의 오류 | 홈에서 "소셜 로그인에 실패했습니다. 잠시 뒤 다시 시도해 주세요"가 떠요 |

닉네임 정하는 화면(소셜 가입)은 이래요.
- "카카오로 가입"(또는 "구글로 가입") 제목 아래, 받은 이메일이 보이고 닉네임 칸에 제공자 닉네임이 미리 들어 있어요. 한글 · 영문 · 숫자가 아닌 글자는 빼고 10자로 잘라요. 남은 글자가 2자보다 적으면 빈칸이에요.
- 닉네임 규칙은 이메일 가입과 같아요. **가입하기**를 누르면 가입과 동시에 로그인되고 "가입이 완료되었습니다. 환영해요!"와 함께 홈으로 가요.
- 이메일 가입처럼 내 블로그("닉네임의 블로그")와 기본 다이어리 "일기장"이 생겨요. 이메일 인증은 카카오 · 구글이 한 것으로 대신해요.
- 이 화면의 정보는 그 브라우저의 로그인 세션에만 있어요. 세션이 없거나 만료됐으면 "소셜 가입 정보가 없거나 만료되었습니다. 처음부터 다시 시도해 주세요"가 떠요.

소셜로 가입한 계정에는 아무도 모르는 비밀번호가 들어가고, 서버에 "비밀번호를 정하지 않음"으로 적혀요(v1.8.1). 이 계정은 가입한 카카오 · 구글로만 로그인해요(v1.9.0). 비밀번호 찾기로 비밀번호를 정할 수도 없어요.

### 로그인 유지와 다른 기기

- 로그인하면 브라우저에 `MYBLOG_SESSION` 쿠키가 생겨요. 7일 동안 유지돼요.
- 사이트를 쓸 때마다 다시 7일로 늘어나요. 그래서 7일 안에 한 번이라도 들어오면 계속 로그인된 채로 있어요.
- 로그인 기록은 Redis(빠른 메모리 저장소)에 있어서, 서버를 새로 배포해도 로그인이 풀리지 않아요.
- 여러 기기에서 동시에 로그인할 수 있어요. 개수 제한은 없어요.
- 비밀번호를 바꾸면 다른 기기, 비밀번호 찾기로 바꾸거나 탈퇴하면 모든 기기의 로그인이 끊겨요. 끊긴 기기에서 다음에 무언가 하면 로그인 창이 떠요.

### 로그아웃 (회원)

머리글의 이름 메뉴에서 로그아웃을 눌러요. 그 기기의 로그인만 끝나요. 다른 기기는 그대로예요.

### 비밀번호 찾기 (방문자)

1. 로그인 창의 "비밀번호를 잊으셨나요?"를 누르면 `/password-reset` 화면으로 가요.
2. 이메일을 넣고 인증번호를 받아요. 화면에는 "입력하신 이메일로 안내를 보냈습니다. 10분 안에 인증번호를 입력해 주세요"가 떠요.
3. 번호를 확인하고 새 비밀번호와 확인을 넣어요.
4. 바꾸면 첫 화면으로 가고 로그인 창이 "비밀번호를 변경했습니다. 새 비밀번호로 로그인해 주세요"와 함께 떠요.

알아 둘 점이 있어요.
- 가입하지 않은 이메일(또는 탈퇴 신청한 이메일)을 넣어도 화면은 똑같이 "보냈습니다"라고 해요. 다만 번호가 만들어지지 않아서 어떤 번호를 넣어도 "인증번호가 만료되었습니다"가 떠요. 다시 받기 간격과 하루 횟수는 똑같이 세요.
- 카카오 · 구글로 가입한 계정의 이메일을 넣어도 화면은 똑같이 "보냈습니다"라고 해요. 다만 인증번호는 만들지 않고, 제목이 "[사각] 비밀번호 찾기 안내"인 메일로 어느 방법으로 로그인하면 되는지 알려 줘요(v1.9.0). 본문은 "이 이메일은 사각 카카오로 가입한 계정이라 비밀번호가 없습니다."로 시작하고, 로그인 창에서 **카카오로 시작하기**(구글이면 **구글로 시작하기**)를 눌러 로그인해 달라고 적혀 있어요. 이 메일도 다시 받기 간격과 하루 횟수를 똑같이 세요.
- 바꾸면 잠금이 풀리고, 모든 기기에서 로그아웃되고, "비밀번호가 변경되었습니다" 메일이 가요(메일 모드가 `log`면 서버 로그에만 찍혀요).
- 인증번호는 메일로만 받아요. 메일 모드가 `log`여도 화면에는 보이지 않아요.
- 로그인한 상태로 이 화면에 오면 "로그인한 상태에서는 내 정보에서 비밀번호를 변경해 주세요"가 떠요. 서버도 로그인한 사람의 비밀번호 찾기 요청은 거절해요.

### 내 정보 (회원)

`/me`에서 해요. 로그인하지 않았으면 로그인 창이 떠요. 위쪽에 "내 블로그", "블로그 관리" 바로가기가 있어요.

- **프로필**: 이메일은 보기만 해요. 닉네임(규칙은 가입과 같음, 내 지금 닉네임은 겹침으로 보지 않음)과 소개(100자까지)를 바꿀 수 있어요. 닉네임을 바꿔도 블로그 이름은 그대로예요.
- **연결된 계정**(v1.8.1): 카카오 · 구글로 가입한 회원은 이메일 아래에 "카카오 계정으로 로그인해요"처럼 보여요. 이메일로 가입한 회원은 이 줄이 없어요.
- **비밀번호 변경**: 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인을 넣어요. 새 비밀번호가 지금과 같으면 "현재 비밀번호와 다른 값을 입력해 주세요"가 떠요. 바꾸면 지금 기기는 그대로 두고 다른 기기만 로그아웃돼요. "비밀번호가 변경되었습니다" 메일도 보내요.
- 저장하지 않은 내용이 있는데 다른 화면으로 가려고 하면 한 번 물어봐요.
- 카카오 · 구글로 가입한 회원에게는 **비밀번호 변경**이 아예 보이지 않아요(v1.8.1). 서버도 이런 회원의 비밀번호 변경 요청은 "소셜 로그인으로 가입한 계정은 비밀번호가 없습니다"로 거절해요.

### 탈퇴 (회원)

1. 내 정보 맨 아래에서 비밀번호를 넣고 "위 안내를 모두 확인했습니다"에 체크해요. 체크해야 **탈퇴하기** 버튼이 눌려요.
2. "정말 탈퇴하시겠습니까? 30일 안에 로그인하면 복구할 수 있습니다"를 한 번 더 확인해요.
3. 탈퇴하면 첫 화면으로 가고, 모든 기기에서 로그아웃돼요.

카카오 · 구글로 가입한 회원은 비밀번호가 없으니, 가입한 소셜 계정으로 다시 로그인해 본인을 확인하고 탈퇴해요(v1.9.1). v1.8.1의 "탈퇴합니다" 입력은 없어졌어요.
1. 비밀번호 칸 대신 "비밀번호 대신 카카오 계정으로 본인을 확인합니다. 카카오 로그인 화면에서 가입한 계정으로 다시 로그인하면 탈퇴가 완료됩니다."(구글이면 "구글 …")가 보여요.
2. "위 안내를 모두 확인했습니다"에 체크하고 **카카오로 확인하고 탈퇴하기**(또는 **구글로 확인하고 탈퇴하기**)를 눌러요. "정말 탈퇴하시겠습니까?…"를 한 번 더 확인해요.
3. 카카오 · 구글 로그인 화면으로 가요. 이미 로그인돼 있어도 카카오는 다시 로그인하게, 구글은 계정을 다시 고르게 해요.
4. 돌아오면 결과에 따라 이렇게 돼요. 확인은 버튼을 누른 뒤 10분 안에 끝내야 해요.

| 경우 | 결과 |
| --- | --- |
| 가입한 계정으로 로그인함 | 탈퇴하고 모든 기기에서 로그아웃돼요. 홈에서 "탈퇴 신청이 완료되었습니다"가 떠요 |
| 다른 계정으로 로그인했거나 10분이 지남 | 탈퇴하지 않고 로그인도 그대로예요. 내 정보에서 "가입한 계정과 다른 계정으로 확인해 탈퇴하지 않았습니다. 가입한 계정으로 다시 시도해 주세요"가 떠요 |
| 카카오 · 구글 화면에서 취소함 | 탈퇴하지 않고 내 정보에서 "탈퇴 확인을 취소해 탈퇴하지 않았습니다"가 떠요 |

탈퇴한 뒤 30일 동안은 이렇게 돼요.
- 회원 정보는 지우지 않고 "탈퇴 신청" 표시만 해 둬요.
- 내 블로그와 글은 다른 사람에게 보이지 않아요. 내가 남의 글에 단 댓글은 "탈퇴한 사용자"로 보여요.
- 같은 이메일로 새로 가입할 수 없어요.

### 탈퇴 복구 (탈퇴 신청한 사람)

30일 안에 같은 이메일과 비밀번호로 로그인하면 "탈퇴 신청한 계정입니다. ○○까지 복구할 수 있습니다. 지금 복구하고 로그인할까요?"라고 물어요.
- 확인을 누르면 탈퇴 표시가 지워지고 그대로 로그인돼요. 블로그와 글도 다시 보여요.
- 취소를 누르면 로그인하지 않고 "탈퇴 신청한 계정입니다. 복구하려면 다시 로그인해 주세요"가 떠요.

소셜 가입 회원은 이메일로 로그인할 수 없으니, 30일 안에 **가입한** 카카오 · 구글 계정으로 로그인하면 이메일 로그인과 같은 "탈퇴 신청한 계정입니다. ○○까지 복구할 수 있습니다. 지금 복구하고 로그인할까요?"를 물어요(v1.9.2, 그전에는 묻지 않고 바로 복구했어요).
- 확인을 누르면 복구하고 로그인하고, "탈퇴 신청을 취소하고 계정을 복구했어요. 다시 만나서 반가워요!"가 떠요.
- 취소를 누르면 탈퇴 상태 그대로 로그인하지 않고 "탈퇴 신청한 계정입니다. 복구하려면 다시 로그인해 주세요"가 떠요.
- 묻는 정보는 그 브라우저 세션에 10분 동안만 있어요. 지나면 "복구 정보가 없거나 만료되었습니다. 다시 로그인해 주세요"가 떠요.

### 30일이 지나면 (자동)

매일 새벽 4시 40분(한국 시간)에 서버가 30일이 지난 탈퇴 회원을 정리해요.
- **지워요**: 블로그, 다이어리, 글(그 글의 댓글·좋아요·태그 연결·신고·통계·사진 포함), 내가 누른 좋아요, 임시저장 글, 내가 올린 사진 파일
- **바꿔요**: 이메일은 `del_랜덤@deleted.invalid`, 닉네임은 `del` + 랜덤 7자, 비밀번호는 어떤 값과도 맞지 않는 값, 소개는 빈 값
- **남겨요**: 회원 번호, 남의 글에 단 댓글("탈퇴한 사용자"로 보임), 내가 한 신고 기록

이메일이 바뀌니까 이 뒤에는 같은 이메일로 다시 가입할 수 있어요. 복구는 더 이상 안 돼요.

## 알아 두면 좋은 것

- **Redis가 꺼지면** 로그인이 안 되고, 인증번호도 받을 수 없어요("잠시 뒤 다시 시도해 주세요"). 로그인 없이 글을 읽는 건 돼요.
- 로그인 실패 횟수와 잠금은 Redis가 아니라 PostgreSQL의 회원 표에 적어요. 그래서 배포하거나 Redis를 다시 켜도 잠금은 그대로예요.
- 메일 모드가 `log`면 가입 인증번호가 화면에 보여요. 누구든 남의 이메일로 가입할 수 있다는 뜻이니, 진짜 운영하려면 메일(SMTP)을 연결해야 해요. 비밀번호 찾기 번호는 v1.7.1부터 어떤 모드에서도 화면에 보이지 않아요.
- 이메일 가입 직후에는 로그인되지 않아요. 로그인 창에서 한 번 더 로그인해야 해요. 소셜 가입은 끝나면 바로 로그인돼요.
- 로그아웃은 그 기기만, 비밀번호 변경은 다른 기기만, 비밀번호 찾기와 탈퇴는 모든 기기를 로그아웃해요.
- 탈퇴한 30일 동안은 같은 이메일로 가입할 수 없고, 비밀번호 찾기도 번호가 오지 않아요. 로그인해서 복구하는 길만 있어요.
- 닉네임을 바꿔도 블로그 이름("닉네임의 블로그")은 안 바뀌어요. 블로그 이름은 블로그 관리에서 따로 바꿔요.
- 운영 로그인 쿠키에는 v1.7.1부터 Secure 표시(HTTPS에서만 보내기)가 붙어요. 로컬 개발(http)에서는 꺼져 있어요.
- **소셜 가입 회원의 비밀번호**: 비밀번호가 없어서 비밀번호 변경이 숨겨지고(v1.8.1), 가입한 소셜 계정으로 다시 로그인해 탈퇴하고(v1.9.1), 가입한 소셜 계정으로 로그인해 복구해요. 비밀번호 찾기로 비밀번호를 정할 수는 없어요(v1.9.0).
- **가입한 방법으로만**(v1.9.0): 예를 들어 카카오로 가입한 뒤 같은 이메일의 구글 계정으로 들어오면 연결하지 않고 "카카오로 가입한 이메일입니다. 카카오로 로그인해 주세요"가 떠요. 탈퇴 중이어도 같아요. 카카오로 들어와야 복구돼요.
- **예전 연결 정리**(v1.9.0): v1.8.0~v1.8.1에서 이메일 가입 계정에 자동으로 붙은 카카오 · 구글 연결은 끊었어요. 그 계정은 이메일과 비밀번호로 로그인해요. 같은 카카오 · 구글 계정으로 들어오면 "이메일로 가입한 계정입니다…"가 떠요.
- **v1.8.0 소셜 가입 회원의 탈퇴 오류**(v1.9.0에서 고침): v1.8.1 전에 카카오 · 구글로 가입한 회원이 "비밀번호가 있는 회원"으로 적혀, 정한 적 없는 비밀번호를 물어 탈퇴할 수 없었어요. 이제 이 회원들도 비밀번호 없는 소셜 가입 회원으로 다뤄요.
