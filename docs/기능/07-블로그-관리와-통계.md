# 07. 블로그 관리와 통계

> 내 블로그를 한곳에서 돌보는 관리 화면(/manage)과, 조회수·방문자를 세서 보여 주는 통계예요.
> 동작 원리는 [원리/07-블로그-관리와-통계.md](../원리/07-블로그-관리와-통계.md)에 있어요.

## 한눈에

- **블로그 관리 화면**: 대시보드 · 글 관리 · 다이어리 관리 · 댓글 관리 · 통계 · 설정, 메뉴 여섯 개가 있어요. 블로그 주인만 들어가요.
- **대시보드**: 오늘 조회수와 방문자, 새 댓글 수, 최근 30일 그래프, 최근 7일 인기 글 5개, 최근 글 5개를 한 화면에 보여 줘요.
- **새 댓글 표시와 읽음 처리**: 남이 단 새 댓글 수가 배지로 뜨고, 댓글 관리를 열면 모두 읽음이 돼요.
- **글 관리**: 비공개 글까지 내 글 전부를 표로 보고, 공개 여부·다이어리로 걸러 보고, 하나씩 지워요. 여러 글을 한꺼번에 옮기거나 지우는 일은 블로그 화면의 다이어리 "편집"에서 해요.
- **통계**: 7일 또는 30일 동안의 조회수·방문자·댓글을 합계와 그래프로 봐요.
- **/api/config**: 화면이 글자 수 제한 같은 서버 기본값을 받아 가는 주소예요.

## 이렇게 써요

### 블로그 관리 화면에 들어가기

로그인한 뒤 이름 메뉴의 "블로그 관리", 홈 화면 계정 상자의 "블로그 관리", 내 블로그 화면의 관리 버튼으로 들어가요. 주소는 `/manage`예요.

- 왼쪽에 블로그 이름, "내 블로그 보기"와 "글쓰기" 버튼, 그리고 메뉴가 있어요. 오른쪽에 고른 메뉴의 내용이 나와요.
- 메뉴 순서는 대시보드, 글 관리, 다이어리 관리, 댓글 관리, 통계, 설정이에요.
- **누가**: 로그인한 회원이 **자기 블로그만** 관리해요. 관리 주소에는 블로그 번호가 없어서, 주소를 바꿔 남의 블로그를 관리할 방법이 없어요. 서버는 로그인한 사람의 블로그를 직접 찾아서 써요.
- 로그인하지 않았으면 로그인을 먼저 하라고 안내해요. 블로그가 없는 회원(예: 아직 만들어지지 않은 경우)에게는 "블로그를 찾을 수 없다"는 화면이 나와요.

### 대시보드

관리 화면 첫 페이지예요. 위에서부터 이렇게 보여요.

1. **숫자 카드 세 개**
   - "오늘 조회수": 큰 숫자가 오늘 조회수, 아래 작은 글씨로 "어제 N · 누적 N".
   - "오늘 방문자": 같은 모양으로 오늘, 어제, 누적 방문자.
   - "새 댓글": 아직 읽지 않은 남의 댓글 수. 1개 이상이면 카드가 강조돼요. "댓글 보기 →"를 누르면 댓글 관리로 가요.
2. **최근 30일 그래프**: 날짜별 조회수와 방문자를 선 두 개로 그려요. 기록이 없는 날은 0으로 찍혀요. "통계 더 보기"를 누르면 통계 메뉴로 가요.
3. **인기 글 (최근 7일)**: 오늘을 포함한 최근 7일 동안 조회수가 많은 글 5개와 그 기간의 조회수예요. 누구나 볼 수 있는 글(공개 글이고, 다이어리도 공개)만 들어가요.
4. **최근 글**: 새로 쓴 글 5개와 작성일이에요. 비공개 글이나 구독자 공개 글도 들어가고, 제목 옆에 표시가 붙어요.

"오늘", "어제"는 **한국 시간 밤 12시**에 바뀌어요.

### 조회수와 방문자는 어떻게 세나

통계 숫자의 바탕이에요. 누군가 글을 열면 이렇게 세요.

- **조회수**: 그 글의 조회수가 1 올라요. 단, 아래 경우에는 세지 않아요.
  - 글쓴이(블로그 주인) 본인이 볼 때
  - 비공개 글일 때
  - 같은 사람이 같은 글을 **30분 안에** 다시 열 때 (새로고침으로 부풀릴 수 없어요)
- **방문자**: 한 사람이 그날 그 블로그의 글을 처음 "조회"할 때 1명으로 세요. 같은 날 같은 블로그의 다른 글을 더 읽어도 1명이에요. 한국 시간 밤 12시에 새로 세요.
- **같은 사람**은 로그인했으면 회원 번호로, 로그인하지 않았으면 브라우저에 남기는 방문자 쿠키(`MYBLOG_VID`, 1년 유지)로 구분해요.
- 구독자 공개 글은 구독자가 보면 세요.
- 누적 방문자는 "하루 방문자"를 날마다 더한 값이에요. 어떤 사람이 사흘 동안 날마다 오면 누적 3명이에요.

### 새 댓글 표시와 읽음 처리

**새 댓글**은 "내가 마지막으로 댓글 관리를 연 뒤, 내 블로그 글에 남이 단 댓글"이에요. 내가 단 댓글은 새 댓글이 아니에요.

- 새 댓글 수는 네 곳에 배지로 떠요: 이름 메뉴의 "블로그 관리", 홈 화면 계정 상자의 "블로그 관리", 관리 화면 왼쪽 메뉴의 "댓글 관리", 대시보드의 "새 댓글" 카드.
- 배지 숫자는 로그인 정보와 같이 받아 와서, 다른 화면에서는 **최대 1분** 늦게 바뀔 수 있어요.
- 댓글 관리를 열면 그 순간 새 댓글이 **모두 읽음**이 돼요. 2쪽만 열어도 전부 읽음이 돼요. 열고 나면 이름 메뉴, 관리 메뉴, 대시보드 숫자를 바로 새로 받아 와서 배지가 사라져요.

### 댓글 관리

내 블로그 글에 달린 **모든 댓글**(내가 단 댓글과 답글 포함)을 최신순으로 봐요. 한 쪽에 10개씩이에요.

- 한 줄마다 보이는 것: "NEW" 표시(새 댓글일 때), "답글" 표시(답글일 때), 쓴 사람 닉네임, 쓴 시각, 댓글 앞부분 50자(줄바꿈은 빈칸 하나로 바꿔요), 어느 글의 댓글인지 제목.
- 글 제목을 누르면 그 글의 해당 댓글 위치로 가요.
- 탈퇴한 회원의 댓글은 "탈퇴한 사용자"로 보여요. 탈퇴한 사람의 댓글도 새 댓글로 셀 수 있어요.
- "삭제"로 지울 수 있어요. 블로그 주인은 내 글에 달린 남의 댓글도 지울 수 있어요. 답글이 아닌 댓글을 지우면 그 아래 답글도 같이 지워질 수 있다고 한 번 더 물어요.
- 지워도 목록을 새로 받지 않고 그 줄만 빼요. 그래서 이 화면에 있는 동안 NEW 표시가 그대로 남아요.

### 글 관리

비공개 글까지 포함한 **내 글 전부**를 최신순 표로 봐요. 한 쪽에 10개씩이에요.

- 표의 칸: 제목, 다이어리, 작성일, 공개(공개 · 구독자 공개 · 비공개), 조회수, 댓글 수, 그리고 "보기 · 수정 · 삭제".
- **거르기**: 위의 두 선택 상자로 골라요.
  - 공개 여부: 전체 / 공개 / 구독자 공개 / 비공개
  - 다이어리: 모든 다이어리 / 내 다이어리 하나
  - 고른 값은 주소(`?visibility=...&category=...`)에 남아서 새로고침해도 유지돼요. 거르기를 바꾸면 1쪽으로 돌아가요.
- "삭제"는 확인을 받고 한 글씩 지워요.
- 글이 하나도 없으면 "아직 쓴 글이 없습니다"와 글쓰기 버튼이, 거른 결과가 없으면 "글이 없습니다"가 보여요.

### 여러 글을 한꺼번에 옮기기·지우기 (다이어리 편집)

글 관리 표에는 여러 개를 고르는 칸이 없어요. 한꺼번에 하는 일은 **내 블로그 화면에서 다이어리를 연 뒤 "편집"**을 눌러서 해요(주소에 `?edit=1`이 붙어요). 블로그 주인에게만 보이고, 내 다이어리 안에서만 켜져요.

- 지금 보고 있는 쪽의 글에 체크 상자가 생겨요. "모두 선택"과 "N개 선택됨"이 함께 보여요.
- **옮기기**: 옮길 다이어리를 고르고 "옮기기"를 누르면 확인 뒤 옮겨요. 다른 다이어리가 없으면 이 버튼이 안 보여요. 옮겨도 글의 수정 시각은 바뀌지 않아요.
- **지우기**: "삭제"를 누르면 "댓글과 좋아요도 함께 지워지고 되돌릴 수 없다"고 확인한 뒤 지워요. 글에 넣은 사진 파일도 같이 지워요.
- 끝나면 "글 N개를 옮겼습니다", "글 N개를 삭제했습니다" 알림이 떠요.
- 고른 글 중 하나라도 내 블로그의 내 글이 아니면 아무것도 바꾸지 않고 거절해요.

### 다이어리 관리

관리 화면에서 다이어리 목록을 손봐요.

- **추가**: 이름(1~20자)을 넣고 추가해요. 같은 블로그 안에 같은 이름은 안 돼요.
- **이름 바꾸기**, **위로 / 아래로** 순서 바꾸기.
- **삭제**: 기본 다이어리("기본" 표시가 붙은 것)는 지울 수 없어요. 글이 하나라도 있는 다이어리도 지울 수 없어요. 화면 아래에 "글이 하나라도 있는 다이어리는 삭제할 수 없습니다"라는 안내가 늘 보여요.
- 다이어리의 표지 색, 소개, 공개 설정 같은 자세한 설정은 블로그 화면의 다이어리 설정 창에서 해요(다이어리 문서에서 다뤄요).

### 통계

7일 / 30일 중 골라 봐요. 처음에는 30일이 골라져 있어요.

- 위에 합계 카드 세 개: 조회수 합계, 방문자 합계, 댓글 합계.
- "일별 조회수 · 방문자" 선 그래프와 "일별 댓글 수" 막대 그래프.
- 날짜는 한국 시간 기준이고, 오늘을 포함해 7일 또는 30일이에요. 기록이 없는 날도 0으로 들어가요.
- **댓글 수는 내가 단 댓글도 포함**해서 그날 달린 댓글을 모두 세요. 지금 남아 있는 댓글만 세기 때문에, 댓글을 지우면 지난 날의 숫자도 줄어요.

### 블로그 설정으로 가기

메뉴의 "설정"(`/manage/settings`)에서 블로그 이름, 한 줄 소개, 소개 글, 분야를 바꿔요. 블로그 화면의 "소개 쓰기" 링크도 이곳으로 와요. 자세한 규칙은 블로그 문서에서 다뤄요.

### 화면이 서버 제한값을 받아 쓰기 (/api/config)

화면은 처음에 `/api/config`를 불러 서버의 기본값을 받아 둬요. 로그인하지 않아도 부를 수 있어요.

- 받는 것: 닉네임·비밀번호·자기소개·블로그 이름·소개·글 제목·본문·다이어리 이름과 소개·댓글·태그·신고·사진·검색어·책갈피 폴더 이름의 길이나 개수 제한, 탈퇴 보관 일수, 한 쪽 글 수, 인기 검색어 새로 고침 간격, 임시저장 개수와 자동 저장 간격, 분야 목록.
- 화면은 이 값으로 입력 칸의 "n/200" 같은 글자 수 표시와 "너무 길어요" 안내를 미리 보여 줘요. 진짜 검사는 서버가 다시 해요.
- 서버 설정을 바꾸면 화면 코드를 고치지 않아도 화면의 제한이 따라 바뀌어요.
- 이 주소가 응답하지 않거나 칸이 빠져 있으면 화면에 넣어 둔 기본값(`frontend/src/lib/config.ts`)을 써요.

## 규칙과 숫자

| 항목 | 값 | 바꾸는 곳 |
|---|---|---|
| 대시보드 그래프 기간 | 30일 (오늘 포함) | `myblog.dashboard.chart-days` (화면 제목 "최근 30일"은 `DashboardPage.tsx`에 글자로 박혀 있음) |
| 대시보드 인기 글 기간 | 7일 (오늘 포함) | `myblog.dashboard.popular-days` |
| 대시보드 인기 글 개수 | 5개 | `myblog.dashboard.popular-size` |
| 대시보드 최근 글 개수 | 5개 | `myblog.dashboard.recent-size` |
| 통계 기간 | 7일 또는 30일 (다른 값은 30일로) | `ManageController.java`, `StatsPage.tsx` |
| 통계 처음 기간 | 30일 | `StatsPage.tsx` |
| 같은 사람 조회 다시 세기까지 | 30분 | `myblog.views.dedup` |
| 방문자 세는 단위 | 블로그마다 하루 1번, 한국 시간 자정에 새로 | `KoreanClock.java`, `ViewRecorder.java` |
| 방문자 쿠키 `MYBLOG_VID` 유지 | 1년(365일) | `VisitorIdFilter.java` |
| 글 관리·댓글 관리 한 쪽 개수 | 10개 | `myblog.post.page-size` |
| 댓글 관리 미리보기 길이 | 50자 | `myblog.comment.preview-length` |
| 새 댓글 배지 반영 지연(다른 화면) | 최대 1분 | `frontend/src/api/queries.ts` (`useMe`의 staleTime 60초) |
| 다이어리 이름 길이 | 1~20자 | `myblog.blog.category-name-max` |
| /api/config가 없을 때 쓰는 값 | 화면에 넣어 둔 기본값 | `frontend/src/lib/config.ts` |

## 알아 두면 좋은 것

- **관리 화면은 내 블로그 하나만** 다뤄요. 블로그 번호를 주소로 받지 않으니 남의 블로그를 볼 수 없어요. 한꺼번에 옮기기·지우기 주소는 블로그 번호를 받지만, 서버가 주인인지 확인해요.
- **주인 본인 조회는 세지 않아요.** 내 글을 아무리 열어도 조회수, 방문자, 인기 글 순위가 바뀌지 않아요.
- **Redis가 꺼져 있으면 조회수와 방문자를 세지 않아요.** 글은 그대로 읽혀요. 그동안의 조회는 나중에 채워지지 않아요.
- 조회수는 **글을 연 그 순간 DB에 바로** 더해요. 하루 끝에 몰아서 계산하지 않아요.
- 누적 조회수·방문자는 블로그 전체 기록이라, **글을 지워도 줄지 않아요**. 반면 글 관리 표의 조회수와 인기 글은 그 글과 함께 사라져요.
- 인기 글은 비공개 글, 구독자 공개 글, 구독자 전용·비공개 다이어리의 글을 빼요. 최근 글에는 이런 글도 다 나와요.
- 대시보드 그래프에는 조회수와 방문자 두 선만 그려요. 댓글 그래프는 통계 메뉴에 있어요.
- 댓글 관리를 **열기만 해도** 읽음이 돼요. 읽음을 하나씩 고르거나 되돌리는 기능은 없어요.
