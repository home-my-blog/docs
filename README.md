# 사각 문서

사각(여러 회원이 각자 블로그를 하나씩 운영하는 다이어리형 블로그 서비스)의 문서 저장소예요.

- 사이트: https://sagak.java21.net
- 코드: [home-my-blog/myblog](https://github.com/home-my-blog/myblog) (기술 스택과 기술적 의사결정은 코드 저장소 README에 있어요)

## 어디부터 읽을까

| 폴더 | 무엇 | 이럴 때 |
|---|---|---|
| [`docs/기능/`](docs/기능/00-목차.md) | 기능 설명: 무엇을 할 수 있고, 어떤 규칙과 숫자로 동작하는지 | "이 기능은 어떻게 쓰고, 제한이 뭐예요?" |
| [`docs/원리/`](docs/원리/00-목차.md) | 동작 원리: 그 기능이 코드에서 어떻게 돌아가는지 (공부용) | "로그인하면 서버에서 무슨 일이 생겨요?" |
| [`docs/기획/`](docs/기획/00-안내.md) | 만들기 전(2026-10-01~02)에 쓴 요구사항, 상세 설계, 기술 스택 가안, 가이드 | "처음엔 어떻게 계획했었지?" |

`기능/`과 `원리/`는 같은 번호끼리 짝이에요. 예를 들어 [기능/03-글쓰기와-사진](docs/기능/03-글쓰기와-사진.md)을 읽고 [원리/03-글쓰기와-사진](docs/원리/03-글쓰기와-사진.md)으로 넘어가면 돼요.

`기능/`과 `원리/`는 **지금 코드**를 기준으로 써요. 코드가 바뀌면 같이 고쳐요. `기획/`은 계획 기록이라 고치지 않아요. 실제와 다른 곳이 있으니 지금 동작은 `기능/`·`원리/`를 보세요.
